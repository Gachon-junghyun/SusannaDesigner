## 2. 판독

| 해라 | 통과 |
|---|---|
| 스케치의 선·화살표·메모를 **하나도 빼지 말고** `선/표시 \| 가리키는 것 \| 해석 \| 확실/추정` 표로. 짝 없는 선(글씨 위·아래 가로선)은 조명바·띠·테두리 후보로 두고 묻는다. 표시마다 `python -m ad zoom` 으로 확대해 «선/표시» 칸에 확대판 좌표를 적는다(`grade.md` §1) | 표의 모든 줄이 결과물 체크리스트가 됐다 |
| 치수는 **쓴 숫자**(손 그림 비율은 축척이 아니다). 치수의 **기준점**(어디서 어디까지)을 확인 | 추정 줄은 질문 목록에 |
| 손님 수정 .ai 는 이전 판과 **요소별 표**로 비교: 글자·서체·색 hex·위치 mm·테·조명 표시·판 크기 | |
| 도료 견본 사진은 같은 사진 속 흰 카드로 흰 균형 + 먼셀 명도로 화면색(노루 MD 6126 → #456655) | |
| 현장 로고가 바랬으면 카카오맵 로드뷰 미리보기 `…_cube/left_2048.jpg` 로 원색 | |
| 현장 자리 치수는 3D 측정에서. **옛 간판 길이를 새 간판 길이로 가정하지 않는다** | |

## D. 서체 바꾸기 — 🔴 게이트를 «후보에 올리기 전»에

1. 레퍼런스: 네이버 이미지 검색 **세 개 이상**을 탭을 앞으로 띄워 천천히 스크롤해 모으고(썸네일은 `type=a340` 원주소), «글씨 결» 갈래로 묶는다. 설치 글꼴 목록부터 내밀지 않는다(«다 거기서 거기»).
2. 게이트 셋: **라이선스**(눈누 인쇄·BI/CI «사용 가능» + OFL «수정 가능», 공공 서체는 지자체 원문의 «변형 금지»·«출처 표시» 캡처) · **채널 가능**(실제 크기에서 붙은 자모 0, 최소 획 ≥ 채널 최소폭, 속공간 열림) · **결**(사람이 고른 레퍼런스와 맞나).
3. 적용: `clientj/tools/font_variants.py <띠> <ttf>` — 손님 글자의 아랫선·왼끝·높이에 맞추고 전화번호와 60mm, 자간 0.04H. 윤곽을 먼저 합친다(pathops).
3-1. 🔴 **가변 글꼴·글꼴 윤곽을 옮겼으면 겹친 윤곽을 합친다**(pathops 합집합) — 채운 그림으론 멀쩡해도 외곽선 보기·재단에선 A 가로획 같은 겹친 선이 남는다(2026-10-24 고객L, 사람이 잡음). 넘기기 전 `python kit/outline_view.py <pdf> <쪽> [--clip …]` 가 «겹친 윤곽 0건»이어야 통과.
4. 전화번호·작은 글자 서체도 바꿀지 묻는다(기본은 손님 것 그대로). **서체 글자를 손으로 고치지 않는다.**

**통과**: 후보마다 «라이선스 URL · 붙은 자모 0 · 결 한 줄». 하나라도 빠지면 후보에서 뺀다.

## 두 면(모서리) 간판

- 두 판을 **같은 기준면**(옛 띠 앞면)에 짓고 모서리는 45° 맞춤, 위 라인박스는 모서리에서 이어진다(`doan.py --face AB`). 각 면 따로면 `--center`.
- 치수의 기준점이 «모서리~기둥»이면 그 길이에 맞춘다(`--signk`) — 높이가 위층 띠를 덮는지 숫자로 보고 «현장 실측 필요».
- 모서리는 **3배 확대**로 본다(판 끝면·라인 끊김·위아래 덩어리는 전체 화면에선 안 보였다).

## 🔴 치수 먼저 보내기 — 시안·일러를 굽기 «전»에 (사람 결정 2026-10-21)

사람: *«시안 같은 거 잡을 때, 보낼 수 있을 때 치수부터 다 적어서 텔레그램으로 보내는 과정을 넣어 줘»*. 고객K에서 «빨간 로고 크기가 어떤지, 다 노트해서 먼저 사진을 주고 일러로 구워 줘»가 먼저 있었다.

| # | 해라 | 통과 |
|---|---|---|
| 1 | 형태가 정해지면(윤곽·부재가 나오면) 부재마다 크기를 **숫자로 잰다**: 전체 가로·세로·바닥에서 높이, 판, 로고 조각마다 가로·세로·변 길이·놓인 높이, 글자 줄마다 가로·글자 높이, 두께, 받침·봉·브래킷, 박스 | 측정은 스크립트(`dims.json`), 손어림 0 |
| 2 | 치수도(정면 + 필요하면 옆 단면) PNG 와 크기표 PNG 를 만든다. 겹친 치수 글씨가 없나 **확대로** 본다 | 겹침 0 |
| 3 | 텔레그램으로 **글(치수 전부, 단위 mm, 추정 값 표시) + 크기표 + 치수도**를 보낸다. 그림은 JPEG, 한 건마다 결과를 찍는다 | 전송 OK 수 = 보낸 수 |
| 4 | 그 **다음에** 일러 CS6·템플릿 시안을 굽는다. 치수 답이 오면 그걸 반영해서 굽는다 | |

- 안이 여럿이면 크기표 한 장에 안별로 같이. 지난 판과 크기가 달라졌으면 «지난 판 대비» 한 줄(여백을 줄이면 로고·글자가 커진다 같은 것).
- 시안 문서(템플릿)에도 같은 치수가 보이게 넣는다 — 문서와 텔레그램 숫자가 같아야 한다.
- 🔴 **보이기용 과장 값(«실제 60, 옆 모습만 70» 같은 것)은 그 부재의 겉모습에만 쓴다.** 다른 부재 위치·굽힘·다리 길이·모든 숫자는 실제 값으로 짓고, 과장 값은 글·치수·표·캡션 어디에도 적지 않는다(2026-10-22 고객K, 사람 격노).
