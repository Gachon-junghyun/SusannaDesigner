# protocols/trace — 글자·그림 따기 (이미지·PDF·.ai → 벡터)

> **뭐냐:** 손님 이미지·도면 PDF·.ai 에서 글자와 그림을 «다시 그리지 않고» 벡터로 뜨는 단계와 통과 기준.
> **언제 읽나:** «이거 svg 따줘», «이 도면에서 간판만 빼줘», «글씨 따줘», 손님 .ai 를 색별로 나눠야 할 때.
> **안 담는 것:** 작고 흐린 로고를 AI 로 다시 그려 따기 → [`logo.md`](logo.md) §재작업 · 간판 판 조립 → [`sign.md`](sign.md).

## 단계

| # | 해라 | 통과 |
|---|---|---|
| 1 | 원본을 받은 그대로 보관(`src/`), 작업은 사본 | |
| 2 | 판 밖으로 나간 장식은 클리핑이 아니라 **실제로 자른다**(클리핑은 일러가 가려진 것까지 재서 판 크기가 틀어진다) | 시트 안 판 = 목표 비율 |
| 3 | 안티앨리어싱 실금은 실루엣을 닫아 메운다 | 흰 실금 0 |
| 4 | 장식이 글자로 딸려 오지 않았나 측정표 줄 폭을 본다 | 줄 폭 = 눈으로 본 것 |
| 5 | 겹친 윤곽은 합친다(pathops simplify) | 블렌더·일러에서 구멍 0 |
| 6 | 되그림 비교: 벡터를 다시 래스터로 그려 원본과 IoU | 0.95↑(가는 선은 확대판으로 따로) |
| 7 | 2000px↑ 로 확대해 본다(1024px 로는 오돌토돌이 안 보인다). 의심되는 곳은 `python -m ad zoom` 좌표 확대로 원본에서 떼어 본다(SVG·PDF 는 벡터로 다시 그림, `grade.md` §1) | 잔물결·티끌 0 |
| 8 | 번호·상호는 문의 글과 대조(7466 vs 7455 사례) | 다르면 먼저 묻는다 |

## 입체·광택용 윤곽 — 울퉁불퉁 없애기 (사람 지적 2026-10-20, 수산나 포스터 A안)

평면 인쇄에선 안 보이던 윤곽의 잔물결이 **광택 입체로 세우면 반사가 토막으로 끊겨 «울퉁불퉁»으로 보인다.** 작은 래스터(512px 로고 등)에서 딴 윤곽을 3D 로 압출·렌더할 때는 아래를 다 한다. 도구는 `jobs/2026-10_수산나포스터/work/smooth_s.py`(다시 그리기)·`bumps.py`(곡률 판정).

| # | 해라 | 통과 |
|---|---|---|
| 1 | **곡률 그래프부터 본다**(`python bumps.py <윤곽.svg>` → `_curv.png`·`_curvmap.png`). 눈으로 보는 윤곽 그림으로는 안 보인다 | 굽이마다 곡률이 봉우리 하나로 오르내린다. 잔톱니·이중 봉우리가 보이면 다음 단계 |
| 2 | 윤곽을 **모서리에서 토막낸다**: 일부러 꺾인 곳(잘린 끝·각진 모서리)을 찾아 그 사이를 따로 다룬다. 통째로 매끈하게 하면 모서리가 뭉개진다 | 모서리 수 = 원본에서 눈으로 센 수 |
| 3 | 곧은 토막(잘린 끝)은 **정확한 직선**으로 바꾼다 | |
| 4 | 곡선 토막은 **고정 매듭 최소제곱 스플라인**(5차, 호 길이 매개, 토막 하나에 속 매듭 7개 안팎, 끝점은 무게로 붙잡음)으로 맞춘다 | 원래 윤곽과 평균 5px 안팎·최대 20px 안팎(2048 기준) |
| 5 | 내보낼 때는 **스플라인 접선으로 손잡이를 단 베지어**(토막당 40개)로 쓴다 | 마디 수 100개 안쪽 |
| 6 | 모서리는 **작게 둥글려 잇는다**(반경 30px 안팎, 3차 곡선) | 베벨이 겹쳐 «접힌 날개»가 안 생김 |
| 7 | 다시 곡률 그래프 + **같은 자리 렌더 전후 확대**를 나란히 본다(안쪽 굽이·바깥 테두리·잘린 끝 셋) | 반사가 한 줄로 이어짐, 접힘 0 |

**하지 마라 (해 봤고 안 됐다):**
- 블러만 올리기, potrace `opttolerance` 만 올리기 — 잔물결은 줄지만 안쪽 굽이의 꺾임이 남는다.
- 스플라인의 «매끈함 계수»만 올리기 — 이중 봉우리는 그대로고 모양만 원본에서 멀어진다(최대 39px).
- 매끈하게 만든 윤곽을 다시 래스터로 그려 potrace — 529 마디로 도로 울퉁불퉁해진다.
- 촘촘한 직선(L) 다각형을 그대로 블렌더에 — 면이 각져 옆벽 반사가 꺾인다.
- 날카로운 모서리 그대로 베지어 — 예각에서 베벨이 겹쳐 접힌다.

원본 벡터가 있으면 이 단계 전부가 필요 없다 — **먼저 원본 벡터를 찾는다**(수산나 S 마크는 리포·도메인 어디에도 없었다).

## 함정
- 테두리에 닿은 덩이는 벡터화에서 통째로 사라지는데 파일은 멀쩡히 생긴다(«추부추어탕» 에서 ㅂ 만 남음) — 흰 여백 10~14% 를 덧댄다.
- 두 줄 레터링은 부제가 조용히 빠진다(`keep_text`) — 끄고 딴다.
- `get_drawings()` 만으로는 살아 있는 글자가 안 온다(서브셋 CID 폰트는 두부) — 2단계 윤곽화.
- fitz 로 .ai 를 그대로 열면 대지만 그려진다 — 일러에서 대지를 넓혀 저장한 PDF 를 쓴다.
- 회색 경계 화소가 빨강으로 분류되면 검은 선 밑에 빨간 조각이 숨는다 — 빨강은 r−max(g,b)>60 인 화소만.
