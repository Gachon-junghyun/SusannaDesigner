### 🔴 카메라는 선·소실점으로 푼다 — 아는 치수 하나로 어림하지 않는다 (사람 결정 2026-10-28)

사람: *«기둥·천장 같은 라인을 따서 각도와 만나는 지점을 가져다 알고리즘적으로 원근점 및 각도를 찾는 과정을 거치라고 해»*. 10-28 고객L은 문짝 픽셀만으로 거리·높이를 어림해 2~4단계를 건너뛰었다.

| # | 해라 | 통과 |
|---|---|---|
| C1 선 따기 | 구조 선을 방향별로 고른다 — **수직**(기둥 좌우 모서리·문틀 세로·창틀 세로) · **정면 수평**(위층 밑면 턱·창틀 윗선·문 윗선·단 윗면) · **깊이**(안으로 들어간 천장 모서리·기둥 옆면 모서리·돌출부 밑면 옆선·받침 팔). 자동 후보(`cv2.createLineSegmentDetector`)를 띄운 뒤 구조 선만 남기고, 끝점은 `STARTUP/model-lab/space/clientj/tools/refine_line.py` 의 `refine()` 로 경계에 서브픽셀로 붙인다 | 방향마다 선 3개 이상, 선마다 맞춤 rms < 1px |
| C2 소실점 | 방향마다 `refine_line.vp_lsq()`(최소제곱 교점), 이상치는 한 개씩 빼 보며 잔차로 거른다. 수직 소실점이 사진 높이의 수십 배 밖이면 «수직 평행 = 수평 카메라 + 시프트» | 선마다 교점 잔차(px) 기록 |
| C3 내부·회전 | 유한한 직교 소실점이 셋이면 주점 = 세 점 삼각형의 수심, 둘이면 주점 = 화면 가운데 가정, f² = −(V1−P)·(V2−P), 회전 = 각 소실점 방향 (V−P, f) 정규화(`clientj/tools/calib.py` 와 같은 수학, fSpy 방식). **정면 사진**(정면 수평 소실점이 무한)이면 깊이 소실점 + 아는 직사각형(문짝 등) 호모그래피로 f·회전을 푼다 | f 가 기기 상식 안(폰 기본 26mm 환산 ±20%) |
| C4 위치·축척 | 아는 치수(JOB 치수표·실측 시트) 하나로 거리·높이. 여러 장·여러 치수면 `solve_joint.py` 식으로 재투영 오차 최소화 | 점·선 재투영 rms < 3px |
| C5 대조 | 구조 선 전부를 카메라로 되그려 사진 위에 겹친 그림(`camera_check.png`) · 문짝만으로 어림한 값과의 차이 · `camera.json`(f px·주점·회전·위치·근거) → 블렌더 카메라(lens·shift_x/y·회전)에 그대로 | 겹친 그림에서 선이 어긋나지 않음, 채점자에게 camera.json·겹친 그림을 준다 |

## 간판 부재 — 판에 그림을 붙이지 않는다

| 부재 | 짓는 법 | 밤 |
|---|---|---|
| 채널(불 들어오는 글자) | 옆면·앞테 80mm + 앞판(앞테 4mm 안쪽, 손님 테가 있으면 테 안쪽 그대로) | 앞판만 발광 0.9 |
| 스카시(불 없음) | 아크릴 10mm, 판 위 검은 글자는 3mm | 불 없음 |
| 상단 라인 | 라인박스 100mm 돌출 + **앞면 발광**(아래로 쏘지 않는다), `LINE_RGB=1.0,0.50,0.06 --downled 2.2 --glare 0.9 --glarestr 0.45` | 판은 어둡게, 라인 둘레만 번짐 |
| 판 | 녹색 도장(손님 도료 번호), 밤엔 코팅 0·거칠기 0.65 | 가로등 흰 점 없게 |

- 글자는 색별 mm SVG → 커브 → 압출. **SVG 네 귀 1mm 표식으로 축척**, 오브젝트 스케일 금지. Blender `extrude` 는 반두께(80mm 를 그대로 넣으면 168mm).
- 두 면: 같은 기준면 + 45° 맞춤(`--face AB`), 각 면 따로(`--center`), 기둥까지(`--signk K`). 도구 → `clientj/scene/doan.py`·`sign3d.py`.

## 조형물·곡면 — «둥글게»를 그냥 하지 않는다 (2026-10-22 학교 무한대상)

| # | 해라 | 통과 |
|---|---|---|
| 1 | 실물 사진에서 **단면**(띠·관·판, 두께 비)을 먼저 읽는다. 스케치의 선 하나는 두께 정보가 아니다 | 단면 한 줄 + 사진 번호 |
| 2 | **곡선의 결**을 말로 적는다: 고르게 도나 / 끝에서만 꺾이나, 교차·꺾임 각도, 고리 모양(물방울·타원·원) | 각도·모양 한 줄 |
| 3 | **전체 비율**을 숫자로: 가로÷세로, 위아래 고리 크기 차, 기울기. 스케치가 있으면 스케치 값과 나란히 | 숫자 셋 |
| 4 | 사람이 «둥글게»처럼 한 마디로 고치라 하면, 1~3 중 무엇을 바꾸는 말인지 레퍼런스로 정하고, 안 정해지면 두세 안을 저해상도로 나란히 보여 주고 묻는다(INTAKE C1~C4) | 바꾼 칸을 말하고 보여 줌 |
| 5 | 비싼 렌더는 모양을 확인받은 뒤에(미리보기 1/4 크기, 32 샘플이면 10초) | 확인 뒤 본 렌더 |

## 봐라 — 렌더를 열 때마다
- [ ] **전체 화면**(1층 유리·문·차양·보도까지)과 **간판 4배 확대** 둘 다. 사람에게도 둘 다.
- [ ] 음절마다: 구멍·홈(겹친 윤곽)·철자·붙은 자모·줄무늬(z-fighting).
- [ ] 모서리·양 끝 **3배 확대**: 판 끝면 툭 튀어나옴·라인 끊김·옛 간판 잔상.
- [ ] 위·아래 변이 건물선과 평행 · **보정 뒤 간판 가로세로비 = 렌더**(fix_tilt 가 75~82% 로 누른 적 있음).
- [ ] 밤: 스카시·판 꺼짐, 라인 빛 방향, 판 색이 떠 보이지 않음.
- [ ] 광택 입체(로고·글자 압출): 반사가 굽이를 따라 **한 줄로** 이어지나. 끊기거나 물결치면 윤곽이 울퉁불퉁한 것 → [`trace.md`](trace.md) §입체·광택용 윤곽(곡률 그래프 → 토막 → 스플라인 → 둥근 모서리).
- [ ] 높이: 간판(+라인)이 현장 자리(측정 ±15%)에 들어가나 → «제작 전 실측 필요» 한 줄.
