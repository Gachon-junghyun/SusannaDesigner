## 새로 만들기

| # | 해라 | 통과 |
|---|---|---|
| 1 입력 | 상호·부제·업종·인상 1~2·안 낼 인상 1·건물 사진·간판 종류·크기를 JOB.md 에. 모르면 «가정» | 철자를 음절로 대조 |
| 2 레퍼런스 | 크롬으로 직접 본다(한국 가게면 한국어 검색). 손잡이 값(획 대비·끝 모양·자간·색)으로 분해 | 공통점 셋·안 쓸 것 하나. 다음 단계엔 예시 셋 이하. **남의 로고는 첨부하지 않는다**(상표) |
| 3 결 하나 | 아래 «결» 표에서 하나. 3안은 그 결 안에서 **손잡이 하나**(글꼴·색·락업)만 바꾼다 | 둘 이상 바꾸면 비교가 안 된다 |
| 4 굵기 | 쓰임 크기에서 거꾸로: 간판이면 `ad check --w-mm` 최소 획·봉 규격, 화면이면 가장 작은 크기(아이콘 48px·명함 2cm). 값과 이유를 프롬프트에 «about N% (because …)» | 가장 가는 곳 ≥ 굵은 획의 1/3. 심벌과 글자 같은 굵기 계열 |
| 5 뽑기 | 공통 틀 + 결 조각. 서로 독립인 안은 `--per-chat 1`. 색은 한 계열 세 벌 | PNG 를 직접 연다. 잉크 1.0(검은 네모)이면 다시. 철자 음절마다. 지어 넣은 띠·도장·글자 없음 |
| 6 판정 | 간판이면 절곡 획 38mm · 조명 글자 203mm · 속공간 30mm · 잡티 400mm² | «불가»면 무엇을 바꿔야 하나 적고 불가 안도 붉게 같이 낸다 |

**공통 프롬프트 틀**: `Create an image:`(ChatGPT) / 글로 답하면 `Generate an image.`(제미나이) · «Flat vector logo, solid black on a pure white background, NO gradient, NO texture, NO shadow, NOT a mockup … fills about the central 50-60%, clear wide white margin, nothing touches the edge. ONE single logo only» · 한글은 음절을 풀어 한 번 더, 쌍자음은 «NOT 지»처럼 틀릴 모양을 이름 불러 막는다 · 심벌이면 `NO text, NO letters`.

**AI 티 빼기(사람이 되돌린 것)**: monoline + 둥근 끝 = «캡슐 같다» · 모티프를 그림 그대로 그리지 않는다(생략 수준은 손님 원안에서 잰다) · 기본은 면 몇 개 · 색은 한 계열 · «그라데이션»은 광택·그림자·빛 번짐까지 포함, 간판 채널엔 불가.

**엔진**: 지시 따르기는 ChatGPT, 폭(다양함)은 제미나이 + 레퍼런스 판. 제미나이 «이미지 안 나옴»이 연달아면 ChatGPT 로. 두 엔진 동시 실행 금지(다운로드가 상대 폴더로 샌다). 제미나이는 원본 크기(2266px)로 받는다. 대량 생성 금지.

## 결(스타일)별

| 결 | 언제 | 핵심 프롬프트·요령 | 통과·주의 |
|---|---|---|---|
| 뷰티 | 네일·왁싱·피부·스파 | «LIGHT weight thin even strokes, WIDE and LOW, VERY generous letter-spacing, NO swashes» · 색 세 벌(블러시·로즈브라운 / 올리브+크림 / 토프·코코아) · `ad respace` 두 단계 | 스와시가 몰래 붙지 않았나 · ChatGPT 는 넓은 자간을 잘 안 지킨다 · 간판이면 봉 규격부터 묻는다 |
| 선(라인아트) | 얼굴 옆선·꽃·동물 | 까치발이면 «굵고 고른 선, 둥근 끝, 획끼리 닿게 1~3조각» · 뾰족한 끝은 벡터를 불리지 말고 `ad redraw --blunt` | `ad fabcheck` · 조각 수 · 티끌 0 |
| 붓 | 한식·노포 | 굵은 붓과 마른 붓을 나눠 · «NO capsule ends, NO monoline — chiseled, tapered» · 간판이면 «붓끝 그대로» + «`--blunt` 시공안» 두 벌 | 벡터에서 `straighten` 금지 · 발·귀·혹은 유지/펴기 두 안 |
| 고급 | 세리프·모노그램 | 형용사 대신 손잡이 · 한글 명조 스와시는 자리 지정(ㅈ 첫 획 등) · 꾸밈 빼기 «PLAIN and HONEST» · `ad squash` | 길쭉해지지 않았나 · 스와시가 부제에 0mm 로 닿지 않나 |
| 글자만 | 워드마크 | **글꼴을 먼저 대 본다**, 안 맞으면 AI 레터링을 옮기기만 · 새 낱말은 `--ref` + «NEW lettering, EXACTLY the same style» · 두 줄은 `ad vec`(keep_text 끔) | 글자 대비 3↑ · 판정은 앉힌 글자 높이로 |
| 굵은 손글씨 | 낙서·마커 | 영어 브랜드명으로 레퍼런스 · 블록·버블·만화·마커 · `vecc --engine potrace --no-snap` | 크레용 질감 금지 |
| 면 | 기본 · 실루엣 | «flat vector logo symbol, solid fills only, NO gradient, NO text» · 각진 면 `vecc`, 둥근 면 `vecc --engine potrace` | 큰 면 3~4개 · 잔선 0 · 아이콘 크기에서 읽히나 · 까치발에 가장 유리(39mm, 2조각) |
| 엠블럼 | 배지·도장 | 얇은 테두리 배지·원호 글자 피함 · 손님 엠블럼은 «AS FAITHFULLY AS POSSIBLE» · 여러 색은 `multitrace.py` | 칠 색 수 = 팔레트 · 그라디언트 0 · 흰 네모 0 |
| 귀여움 | 마스코트 | «예쁘게 · NOT a cartoon, NOT a kawaii emoji» · 비율을 숫자로(미검증) | 근거 한 건뿐 |
| 입체·광택 | 화면용 한 벌 | 평면 SVG 가 원본, `ad flatfx`/`ad render3d` | 브랜드색이 분홍으로 뜨는 문제 미해결 |

## 손님 로고 재작업(작고 흐림)

12. AI 두 곳에 `--ref` «그대로 깨끗하게» → 원본 크기로 받기 → `ad upscale` → potrace(흐림 2 · opttolerance 0.8 · alphamax 1.0). **매끈함은 점을 적게에서 나온다**(1,266 → 257 곡선).
- 선만 보기 «층·꺾임»: **일러 화면(선만 보기)부터 본다** → 점을 꺼내 몇 토막·몇 도·몇 pt 인지 확정 → `ad straighten`(±3°, 1.5° 안은 축에 세움, 모서리 원호 상한 12pt, `--humps` 는 두 안으로) → 같은 화면으로 전후.
- 곡선 «다시 맞추기»는 하지 마라 — 앵커만 늘었다(112 → 149).
- 그라디언트 PDF 를 다시 열면 «윤곽 클립 + 큰 네모»가 생긴다 → 색 시안은 패스에 직접 칠하고, 재단은 `ad cutfile`(칠 없음, 검정 0.25pt), PDF 는 `_보기용`.
