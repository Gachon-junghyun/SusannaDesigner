## 외관 (고객G 약국 흐름)

| # | 해라 | 통과 |
|---|---|---|
| 1 | 손님 브랜드 매뉴얼·로고 원본을 받는다. 없으면 브랜드 분석 한 장(색·로고·서체 사용 규칙) | 손님 규칙을 어기지 않는다 |
| 2 | 1차: 매뉴얼 형태 그대로 몇 장 + 수산나 템플릿판 | |
| 3 | 사람·손님 손글씨 수정이 오면 **글자 하나하나 판독표**(«파T?» 같은 건 묻는다) | 판독 못 한 글자는 질문 목록 |
| 4 | 등급 나누기(보급·프리미엄): 차이를 «무엇이 달라지나» 한 줄로(재질·조명·높이) | |
| 5 | «둘 다 X 버전» 같은 요청은 물어서 확정(고객G 약국의 좋은 예) | |
| 6 | 최종: 안별 일러 + RGB 값 + 미리보기 | |

## 실내 (고객I 흐름)

| # | 해라 | 통과 |
|---|---|---|
| 1 | 현장 사진 → 일러 평면 1:50 + 전개도 4면(실측은 하나, 나머지 추정 표시) | |
| 2 | **사장님 스케치·그림이 배치의 답**. 짧은 지시가 두 갈래면 렌더 전에 한 줄로 묻는다 | 좌식 위치·액자 건(18컷 + 10장 다시) |
| 3 | 가구 규격은 판매 상세 원문으로(추정 금지) | 출처 링크 |
| 4 | 블렌더 씬, 재질·현판은 AI(사진화 규칙대로) | |
| 5 | 사진화: 배치·탁자 수·간판 보존을 대조, 간판이 없는 컷엔 «간판 없음» | 위에서 본 컷에서 겹침 없음 · 사장님 그림과 같음 |
| 6 | 지킬 물건(액자·벽 그림)은 따로 한 문장(«같은 자리·같은 크기, 지우지 마라») | 빠진 물건 0 |
| 7 | 소품 벡터 + A3 시안집. 시안집엔 결과만(«지식의 저주 빼라») | |
