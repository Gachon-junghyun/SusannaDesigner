# 기법 — 3D 관 조형물

> **뭐냐:** 중심선 곡선(∞, 8, 고리 등)을 타원 단면 관으로 세워 Blender 로 렌더한다. 꼬임, 가로 홈, 밤 점조명까지 재질로 넣고 투명 배경으로 뽑는다.
> **언제 읽나:** 실물 조형물·상징물을 포스터에 입체로 세우기 전. 🔴 `../protocols/modeling.md` §조형물·곡면을 같이 읽는다.
> **안 담는 것:** 곡면 형태를 묻는 법 → `../INTAKE.md` C1~C4 · Blender 함정 → `DeGaJa_Agent/module_render/BLENDER.md`.

## 무엇이 되나
- 넣는 것: 중심선 식과 값(폭·기울기·교차 높이), 단면(폭·두께), 재질 값.
- 나오는 것: 투명 배경 PNG(2100×3900, 384샘플 약 80초).

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 받아들여진 값 |
|---|---|---|
| 곡선 종류 | Gerono 는 위아래 끝에서만 꺾이고 가운데가 곧은 X(«너무 8, 끝만 돈다»). 베르누이는 전체가 고르게 돎 | 베르누이, 폭 0.80, 기울기 0.10 |
| 단면 | 평면 띠는 «너무 평면». 실물은 납작한 타원 관 | 폭 0.22 × 두께 0.15(높이 2 기준) |
| 꼬임 각·퍼짐 | 지수가 작을수록 꼬임이 띠 전체에 퍼짐 | 70°, 지수 0.6 |
| 교차부 앞뒤 거리 | 작으면 관끼리 뚫고 지나감 | 0.17 |
| 가로 홈 수·세기 | 실물의 촘촘한 홈 | 180, 범프 0.25 |
| 점조명 | Voronoi 점 크기·남길 몫·밝기 | 46, 0.12, 0.42, 28 |
| 월드 색 | 반사가 바탕 색 계열로 물듦 | 바탕(학교 블루) 쪽 어두운 파랑 |

## 함정
- 모양을 한 마디(«둥글게»)로 받고 바로 고치면 비율이 판 밖으로 나간다 → 미리보기(1/4 크기, 32샘플, 10초)로 확인받고 본 렌더.
- 스케치의 선 하나는 두께 정보가 아니다 → 실물 사진에서 단면부터.
