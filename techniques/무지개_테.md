# 기법 — 무지개 테 (박막 간섭 결)

> **뭐냐:** 무채색 그림의 «몇 군데»에만 무지개 띠를 얹는다. 고리 윤곽을 따라 빨강·노랑·초록·파랑·보라 띠가 도는 테, 그리고 밝은 점을 파랑 → 초록 → 노랑 → 빨강 동심원으로 바꾼 점. 판 전체 채널 밀기(색수차)와 다르다.
> **언제 읽나:** 흑백·금속 그림에 색 포인트를 줄 때, «홀로그램», «비눗방울 막», «무지개 반사»를 낼 때.
> **안 담는 것:** 바탕 금속 → `액체_크롬_반사.md` · 결의 값 → `../styles/액체_크롬/STYLE.md` · 레퍼런스(남의 것) → `../refs/_모음/포스터_그리드/36_liquid_chrome/z1_무지개테.png`·`z2_색점.png`.

예시 그림 없음(재현 전).

## 무엇이 되나
- 넣는 것: 무채색 그림 한 장 + 색을 얹을 자리(윤곽 두세 곳, 밝은 점 한두 곳).
- 나오는 것: 같은 그림에 강한 색이 5% 안팎만 박힌 판.

## 레퍼런스 실측 (1125×2000, 2026-10-23)
| 잰 것 | 값 | 재는 법 |
|---|---|---|
| 강한 색 넓이 | 채도 0.5 넘는 곳 4.86%(0.3 넘는 곳 15.5%) | (최대-최소)/최대 |
| 테 띠 두께 | 판 폭의 약 1%, 띠 순서 바깥 주황·빨강 → 노랑 → 초록 → 파랑 → 보라 안쪽 | 확대판 z1 |
| 동심원 점 | 지름 판 폭의 약 7%, 가운데 진파랑 → 초록 → 노랑 → 빨강 | 확대판 z2, 판에 두 개 |
| 나머지 윤곽 | 바깥 주황, 안쪽 파랑의 1~3px 얇은 번짐 | 확대판 z3 |
| 채널 어긋남 | 3×3 칸 중 8칸 0px, 1칸 2~4px | 빨강·파랑 채널 경계 상관이 최대가 되는 이동 |

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 레퍼런스에 가까운 값 |
|---|---|---|
| 얹는 자리 수 | 많으면 홀로그램 스티커처럼 요란, 적으면 «반짝» 포인트 | 테 2~3곳 + 점 1~2곳 |
| 띠 두께 | 두꺼우면 무지개 그림, 얇으면 빛 번짐 | 판 폭 1% 안팎 |
| 색 순서 방향 | 밝은 쪽에서 어두운 쪽으로 파랑 → 빨강(점), 바깥 빨강 → 안 보라(테) | 레퍼런스 순서 |
| 강한 색 넓이 | 10% 를 넘으면 무채색 결이 무너진다(추정) | 약 5% |

## 함정
- 🔴 이건 «글리치 색 갈림»(미검증 후보, 채널 전체 밀기)과 다르다. 채널을 판 전체로 밀면 모든 윤곽에 같은 번짐이 생겨 레퍼런스의 «몇 군데만 무지개» 결이 안 나온다.
- 밝기에 무지개 그라데이션 맵을 판 전체로 걸면 사이키델릭해진다. 마스크로 자리를 골라 건다.

## 도구
- 경로: `../ad/liquid.py` 의 `overlay(film=3, film_w=0.85, film_r=0.06)` — 비탈 띠에서 두께(높이·기울기)를 색상환으로, 고른 자리 근처에만. 그 밖에 포토샵이면 무지개 그라데이션 맵 레이어 + 자리 마스크, 3D 면 박막(thin film) 재질, 2D 는 밝기 → 색상환 매핑을 마스크 안에서만(numpy, 추정).
- 명령: 없음.

## 쓴 곳 · 어울림
- 스타일: 액체 크롬(2026-10-23 수산나 판에 처음 씀).
- 손잡이 실측: 고리 주기 `thick*1.9` 가 레퍼런스에 가깝다(2.6 이면 기름막처럼 줄이 너무 촘촘). 자리 반경 판 폭 6%, 판 끝 12% 안에는 두지 않는다(끝에서 띠처럼 늘어남).
- 같이 쓰면 좋은 기법: 액체 크롬 반사 · 마크 압출 3D · 점조명 빛 번짐(빛점 몇 개를 무지개 점으로, 미검증). 골유리 모노크롬과는 안 맞음(무채색이 그 결의 조건).
