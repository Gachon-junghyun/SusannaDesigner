# 기법 — 작은 글 두 서체 짝 (라벨 산세리프 + 값 고정폭)

> **뭐냐:** 제목 말고 모든 글을 아주 작은 한 크기로 두되, «이름표»는 산세리프 대문자, «내용»은 고정폭 소문자로 갈라 짝을 짓는다. 크기를 안 바꾸고 서체로만 위계를 만든다. 정보는 판 폭을 같은 칸으로 나눈 머리띠에 둔다.
> **언제 읽나:** 정보(연락처·주소·서비스)를 조용히 넣어야 할 때, 거대 제목과 함께.
> **안 담는 것:** 실측 원문 → `../refs/_모음/포스터_그리드/35_gosha_yoga/REPORT.md`.
