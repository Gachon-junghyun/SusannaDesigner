# 기법 — 점조명 빛 번짐

> **뭐냐:** 렌더 속 작은 빛점만 골라 번지게 한 레이어를 만들어 포토샵에서 «스크린»으로 얹는다. 가장자리 반사에는 번짐이 안 붙는다.
> **언제 읽나:** 밤 조명·별빛·LED 점을 은은하게 살리고 싶을 때.
> **안 담는 것:** 함정 원문 → `../LESSONS.md` 2026-10-22 [도구] (점조명 빛 번짐).

![예시](_img/점조명_번짐.jpg)

## 무엇이 되나
- 넣는 것: 판 크기 투명 렌더 PNG.
- 나오는 것: 검정 바탕 RGB 번짐 PNG(스크린용). 문자 아트에서는 빛 문자 `*` 자리로도 쓴다.

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 받아들여진 값 |
|---|---|---|
| 가로 막대 열기(top-hat) 길이 | 가로로 긴 반사(홈)를 빼는 정도 | 31px |
| 덩어리 거르기 | 넓이·가로세로비 위면 반사로 보고 버림 | 260px 이하, 2.2 안 |
| 번짐 반경·세기 | 큰 번짐 + 작은 번짐 두 겹 | 18px·4px, 세기 1.6 |
| 색 | 따뜻한 흰색 | (1.0, 0.97, 0.90) |

## 함정
- 밝기 문턱만 쓰면 관 가장자리 반사가 같이 잡혀 윤곽 전체에 후광이 생긴다(점 픽셀 129,586 → 17,950 으로 거른 뒤 통과).
