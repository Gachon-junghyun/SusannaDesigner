# 기법 — 레퍼런스 해부 배치

> **뭐냐:** 남의 포스터를 그리드로 해부한 숫자(제목 글자 %H, 단계 배율, 그림 넓이·자리)로 우리 포스터의 첫 배치를 잡거나, 완성본이 이상하지 않은지 대조한다.
> **언제 읽나:** 사람 스케치 없이 포스터 배치를 처음 잡을 때. 스케치가 있으면 대조용으로만.
> **안 담는 것:** 단계 본체 → `../protocols/promo.md` §포스터 레퍼런스 해부 · 숫자 모음 → `../refs/_모음/포스터_그리드/SUMMARY.md`.

## 손잡이
| 값 | 모음표 중앙값(34장) |
|---|---|
| 제목 글자 높이 | 판 높이의 8.2% |
| 글자 단계 배율 | 1.4 |
| 가장 큰 그림 넓이 | 판의 47.5% |
| 그림 자리 | 정가운데가 가장 많음 |

## 함정
- 스케치가 있는 건에서는 스케치가 이긴다(학교: 모음표는 대조만, 무승부 기록).
- 유형 기준은 레퍼런스가 5장 미만이면 약하다.
