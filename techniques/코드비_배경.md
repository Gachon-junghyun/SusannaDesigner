# 기법 — 코드 비 배경

> **뭐냐:** 판 전체에 코드 문자(0·1·16진수·괄호·기호) 줄기가 위에서 아래로 떨어지는 해킹 화면 배경. 줄기마다 아래 끝(머리)이 밝고 위로 옅어진다.
> **언제 읽나:** 빈 바탕이 «심심하다», «해킹 묘사처럼», «매트릭스 느낌» 요청에.
> **안 담는 것:** 조합 값 → `../styles/아스킷_텍스트/STYLE.md`.

## 무엇이 되나
- 넣는 것: 비워 둘 칸(그림·글자 자리), 판 크기.
- 나오는 것: 문자마다 불투명도가 다른 한 색 레이어 PNG + 원문 txt.

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 받아들여진 값 |
|---|---|---|
| 격자 칸·글자 크기 | 그림 문자보다 굵게 해야 배경으로 읽힘 | 44×62px, 76px(그림 문자의 약 2.2배) |
| 불투명도 범위 | 🔴 «은은하게»를 낮게 잡으면 안 보인다 | 0.10~0.42 «안 보일 지경» → **0.22~0.60** |
| 줄기 수·길이 | 풍성함 | 230개, 4~26칸 |
| 머리 밝기 | 줄기 끝이 반짝임 | 1.6배 |
| 흩뿌림 | 줄기 사이 잔글자 | 5% |
| 범위 | 판 전체 / 한 줄 아래만 | 판 전체(«아예 위부터 아래까지») |
| 강조 점선 | 한 줄을 가장 밝게 | 썼다가 «없애 줘» |
| 문자 모음 | 해킹 느낌을 정함 | `0 1 { } [ ] < > / \ | ; : = + * # $ % & ? ! _ ~ ^` + 16진수 |

## 함정
- 그림·글자 둘레를 안 비우면 윤곽이 배경에 묻힌다 → 둘레 한 칸 + 글자 잉크 상자 안을 비운다.
- 무작위는 씨앗(`seed`)을 값으로 둬야 다시 돌려도 같은 판이 나온다.
