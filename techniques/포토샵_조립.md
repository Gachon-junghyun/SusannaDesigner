# 기법 — 포토샵 레이어 조립

> **뭐냐:** 파이썬에서 포토샵 COM 으로 새 문서를 만들고, 레이어 PNG·문자 레이어·안내선을 넣어 PSD·PNG·JPG·PDF 를 한 번에 저장한다. 사람이 포토샵에서 레이어를 켜고 끄며 고칠 수 있게 넘기는 방법.
> **언제 읽나:** «포토샵으로 만들어», «PSD 로 줘», «배치는 내가 할게» 요청에.
> **안 담는 것:** 포토샵·일러 COM 일반 함정 → `../LESSONS.md` [템플릿] 10-20(안내선), DeGaJa 메모리 «일러는 COM 전에 먼저 띄우기».

## 무엇이 되나
- 넣는 것: 레이어 목록(파일·이름·혼합·보임·불투명도, 아래 → 위), 바탕색, 숨김 참고 레이어, 안내선, (선택) 문자 레이어.
- 나오는 것: 레이어 PSD + 합친 PNG·JPG + 인쇄용 PDF.

## 손잡이
| 값 | 효과 |
|---|---|
| 레이어 나눔 | 색별·역할별로 나누면 사람이 «명암 끄기», «배경 세기» 를 불투명도로 바로 고친다 |
| 참고 레이어(숨김) | 원래 스케치·3D 렌더를 숨겨 넣으면 다음 수정의 출발점이 된다 |
| 문자 레이어 | 글자를 고칠 수 있게. 크기는 px 로 주면 어긋날 수 있어 시험 글자 잉크 높이로 비례 보정 |

## 함정
- 포토샵을 Dispatch 로 띄우지 말고 먼저 `Start-Process` 로 띄워 창 제목을 확인한다.
- 내가 만든 문서만 닫는다(try/finally). 사람이 열어 둔 문서를 건드리지 않는다.
- 경로는 정슬래시로 넘긴다.
- 라틴 문자 레이어는 `position` 이 기준선이다. 한글은 잉크 상자 가운데로 놓는다.
