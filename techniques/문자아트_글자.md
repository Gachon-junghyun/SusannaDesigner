# 기법 — 문자 아트 글자

> **뭐냐:** 서체로 쓴 큰 글자를 문자 격자로 다시 짠다. 가장자리는 방향 문자, 속은 가장자리에서 멀수록 진한 문자라 입체 테두리처럼 보인다.
> **언제 읽나:** 제목·큰 글자를 문자 아트로 만들기 전.
> **안 담는 것:** 글자를 칸에 쌓는 배치 → `네모칸_쌓기.md` · 조합 값 → `../styles/아스킷_텍스트/STYLE.md`.

![예시](../styles/아스킷_텍스트/zoom_조형물.jpg)

## 무엇이 되나
- 넣는 것: 글자, 바탕 서체 파일, 칸 배치(어디에 얼마나 크게).
- 나오는 것: 흰 문자 레이어 PNG(그림 문자와 같은 격자라 한 화면처럼 맞물림).

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 받아들여진 값 |
|---|---|---|
| 바탕 서체 | 네모꼴일수록 칸에 꽉 차고 문자 격자와 잘 맞음. 획이 가늘면 작은 글자에서 문자가 듬성해져 안 읽힘 | 배민 도현(본문 글자), 짧고 넓은 글(D-4)은 Black Han Sans |
| 켜짐 문턱(`glyph_on`) | 낮추면 획이 두꺼워짐 | 0.45 |
| 속 깊이 단계 | 가장자리에서 칸 1.4·2.6 넘으면 한 단계 진하게 | `%` → `#` → `@` |
| 둘레 비움 | 글자 잉크 상자 안과 둘레 한 칸은 배경 문자를 비움 | 켬 |

## 함정
- 가는 서체를 작게 쓰면 «D -4» 처럼 획이 끊겨 보였다 → 굵은 네모꼴 서체로.
- 배경 문자가 획 사이 틈으로 끼면 글자가 안 읽힌다 → 잉크 상자 안을 통째로 비운다.
- 서체 라이선스: 글자 모양을 «그림처럼» 쓰는 것도 서체 사용이다. 눈누 라이선스 표에서 인쇄 «사용 가능»을 먼저 본다(D7).
