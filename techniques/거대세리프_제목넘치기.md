# 기법 — 거대 세리프 제목 넘치기

> **뭐냐:** 고대비 세리프 한 단어를 판 높이의 3분의 1 크기로 키워 판 폭보다 길게 깔고(끝 글자가 잘림), 사진이 그 아래로 들어가게 겹친다. 위계를 크기 한 번의 큰 낙차로만 만든다.
> **언제 읽나:** 이름 하나가 주인공인 판, «에디토리얼», «잡지 표지», «고급스럽게 크게».
> **안 담는 것:** 이 기법을 쓴 결 → `../styles/에디토리얼_세리프/STYLE.md` · 실측 원문 → `../refs/_모음/포스터_그리드/35_gosha_yoga/REPORT.md`.

## 무엇이 되나
- 넣는 것: 짧은 단어(4~6자), 고대비 세리프 서체, 사진 한두 장.
- 나오는 것: 제목이 판을 지배하고 나머지는 작은 장식처럼 물러나는 판.

## 손잡이 (값 → 보이는 효과)
| 값 | 효과 | 레퍼런스 값 |
|---|---|---|
| 제목 잉크 높이 | 키울수록 «글자가 그림»이 됨. 모음표 중앙값은 9.5%H | 33.2%H |
| 판 폭 대비 제목 길이 | 100% 넘기면 끝 글자가 잘려 «판 밖으로 계속»되는 느낌 | 102.9%, 왼쪽 여백 1.8%W |
| 제목 대 둘째 크기 배율 | 클수록 조용하고 고급, 중간 크기를 두면 결이 깨짐 | 약 20 |
| 겹침 순서 | 제목이 사진 «위»면 글자가 주인공, «아래»면 사진이 주인공 | 제목이 위(H 다리가 사진을 덮음) |
| 합자·대체 글자 | 한 글자를 길게 늘려 다른 글자를 가로지르게 하면 손맛이 생김 | S 꼬리가 H 를 가로지름 |

## 함정
- 가는 획이 머리카락 굵기라 작은 판(명함·썸네일)에서는 사라진다. 인쇄 A3 이상·폰 화면 전체에서만.
- 한글 제목으로 옮기면 고대비 명조로 바꿔야 하는데 결이 달라진다(미검증).
- 서체 이름을 확인 못 했다 — 비슷한 무료 서체(Gloock · Bodoni Moda)로 비교판부터.
