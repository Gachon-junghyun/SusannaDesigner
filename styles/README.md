# styles — 스타일 대장 (포스터·광고물·홍보물의 «결»)

> **뭐냐:** 우리가 만들어 사람이 받아들인 시각 스타일을 한 장씩(`<이름>/STYLE.md` + 대표 그림) 모은 곳. 새 결을 만들면 여기에 카드를 더한다.
> **언제 읽나:** 포스터·광고물·홍보 이미지를 시작하기 «전»(맞는 결이 있으면 그 카드대로 시작). 한 건을 넘긴 뒤(새 결이면 카드를 만들고, 있던 결이면 카드를 고친다).
> **안 담는 것:** 표현 방법 하나하나(손잡이·함정·도구) → [`../techniques/`](../techniques/README.md) · 남의 포스터 해부 숫자 → `../refs/_모음/포스터_그리드/` · 웹 브랜드 디자인 시스템 → `../design-md/` · 사람이 되돌린 금지 규칙 → `../TASTE.md` · 갈래별 단계 → `../protocols/promo.md`.

## 쓰는 법

1. **시작할 때**: 요청을 받으면 이 목록을 먼저 본다. 사람이 결을 이름으로 부르면(«아스킷으로», «루체른 결로») 그 카드를 끝까지 읽고 «다시 만드는 법»대로 시작한다. 맞는 결이 없으면 새로 만든다는 것을 첫 보고에 말한다.
2. **사용 선언에 같이 적는다**: «수산나 디자이너 CLAUDE.md 의 promo 프로토콜, 스타일 `styles/<이름>` 을 사용하겠습니다.»
3. **새 결을 만들었으면**(목록에 없는 결로 사람이 받아들인 결과물이 나왔으면) 넘긴 같은 턴에 카드를 만든다. 틀은 [`_TEMPLATE.md`](_TEMPLATE.md). 대표 그림(`preview.jpg`, 긴 변 1240px 안팎)과 확대 그림 두세 장을 같이 둔다.
4. **있던 결을 다시 썼으면** 그 카드의 «사람이 고친 것»과 «쓴 건» 표에 한 줄씩 더한다. 값이 바뀌었으면 «결을 정하는 값»을 고친다(항목 하나씩, 통째로 다시 쓰지 않는다).
5. **도구는 경로로 부른다.** 카드에 도구 경로와 바꿀 값을 적고 코드를 복사하지 않는다. 같은 결을 두 번째 건에서 쓰게 되면 그때 도구를 `forge/lib` 나 `ad/` 로 올리고 카드의 경로를 고친다.

## 카드가 갖출 것 (틀: `_TEMPLATE.md`)
- 대표 그림 · 한 줄 정의 · 언제 쓰나 / 안 맞는 곳
- **쓴 기법**: `../techniques/` 카드를 가리킨다(기법 = 다른 결에도 쓰는 표현 방법, 스타일 = 그 조합과 값)
- **결을 정하는 값**(색 값, 바탕, 글꼴과 라이선스, 격자·크기 비율, 레이어 구성) — 숫자로
- **사람이 고친 것**(차수마다 사람 말 그대로 + 바꾼 값). 다음 건이 같은 데서 안 넘어지게 하는 칸이다
- 다시 만드는 법(도구 경로, 바꿔 넣을 것, 명령) · 쓴 건 표
