# STYLE — 아스킷 텍스트 (해킹 화면 문자 아트)

> **뭐냐:** 검정 바탕 위에 그림(조형물·제품), 큰 글자, 배경까지 **전부 고정폭 문자로 짠** 결. 그림은 초록 문자로 윤곽과 명암을, 글자는 흰 문자로 네모 칸에 쌓고, 배경에는 코드 문자 비가 판 전체에 흐른다.
> **언제 읽나:** 사람이 «아스킷», «텍스트 아트», «해킹 느낌», «매트릭스», «코딩 느낌»으로 부를 때. 시작 전에 끝까지.
> **안 담는 것:** 학교 건의 문구·자리 → `../../jobs/2026-10_학교포스터/JOB.md` · 문자 아트 만드는 법의 함정 원문 → `../../LESSONS.md` [도구] 10-22.

확대: [조형물](zoom_조형물.jpg) · [D-4](zoom_D-4.jpg) (대표 그림과 글자·배경 확대판은 공개본에서 뺐다)

## 언제 쓰나 / 안 맞는 곳
- 쓰나: 개발·알고리즘·해커톤·코딩 동아리·IT 행사 홍보, 카운트다운(D-n) 포스터, 상징물 하나를 크게 세우는 포스터.
- 안 맞음: 기업·관공서 손님 본 사이트용(«mz틱» 판정 위험, TASTE), 사진이 주인공인 실적 홍보, 작은 크기(문자 한 칸이 1mm 아래면 문자가 안 읽히고 회색 덩어리가 된다).

## 결을 정하는 값
| 무엇 | 값 | 비고 |
|---|---|---|
| 바탕 | `#000000` | 사람 «배경 검정» |
| 판 | A3 세로 3508×4961, 300dpi | 스케치 비 1:1.414 |
| 문자 격자(그림·글자) | 칸 18×28px, 194칸×177줄, Consolas Bold 34px | 한 글자씩 칸 가운데에 그린다(줄째 그리면 밀린다) |
| 그림 윤곽 | 초록 `#35E06E`, 경계 방향 문자 `- _ / \ |`, 꺾임 `+` | 45° 경계는 두 겹으로 보이는 게 정상 |
| 그림 명암 | 흐린 초록 `#1E8A45`, 밝기 단계 `. : - = + * #` | 따로 레이어. 끄면 윤곽만 |
| 빛 | 흰색, 가장 밝은 반사 5% `:`, 점조명 `*` | |
| 큰 글자 | 흰색. 서체 모양을 칸으로 재서 가장자리는 방향 문자, 속은 가장자리에서 멀수록 `% # @` | 바탕 서체: 배민 도현(눈누 55, 인쇄 가능). 짧고 넓은 글자(D-4)는 Black Han Sans(OFL) — 도현은 그 크기에서 획이 약하다 |
| 글자 배치 | 정사각형 칸을 빈틈없이 세로로 쌓고, 글자 잉크를 칸의 80~88% 정사각형에 맞춤 | 사람 «실루엣이 네모처럼, 간격 맞춰» |
| 배경 문자 비 | 초록 `#35E06E`, 굵은 격자 44×62px·76px, 판 전체, 줄기 230개 길이 4~26, 불투명도 22~60%, 머리(아래 끝)가 1.6배 밝음, 흩뿌림 5% | 문자: `0 1 { } [ ] < > / \ | ; : = + * # $ % & ? ! _ ~ ^` 와 16진수. 그림·글자 둘레 한 칸과 글자 잉크 상자 안은 비운다 |
| 그림 크기 | 판 높이의 80% | 사람 «조금 더 키우고» |
| 레이어(아래 → 위) | 배경 / 배경 문자 비 / 명암 / 윤곽 / 빛 / 글자 / 참고(숨김: 3D 렌더, 스케치) | 색별로 나눠 불투명도로 세기 조절 |

## 사람이 고친 것 (2026-10-22 학교 포스터, 차수 순)
| 차수 | 사람 말 | 바꾼 값 |
|---|---|---|
| 3 | «무한 조형물 윤곽만 따고 + - = 초록·화이트, 배경 검정, 글자도 텍스트 아트» | 파란 바탕 3D → 검정 바탕 문자 아트 |
| 3 | «아스킷 텍스트는 아무거나 써도 돼, 이쁘게 다양하게» | + - = 셋 → 방향 문자·밝기 단계·`% # @` |
| 4 | «심심하다, 점선이 최대고 그라데이션조차 아스킷으로 은은하게, 해킹 묘사처럼» | 배경 문자 비 추가(점선에서 아래로 옅어짐) |
| 5 | «글자 좀 더 크게, 아예 위부터 아래까지, 랜덤으로 풍성하게» | 배경 격자 36×52, 판 전체, 무작위 줄기 |
| 6 | «점선 없애고, 배경 글자 너무 은은해서 안 보일 지경, 학교이랑 무한도 키우고» | 점선 삭제, 배경 44×62·불투명도 0.10~0.42 → 0.22~0.60, 그림 높이 70 → 80%, 글자 약 17% 크게 |
| 6 | «알고리즘 위에 D-4 도» | 짧은 강조 문구는 같은 문자 아트, 굵은 네모꼴 서체 |

🔴 **배경 문자 비는 «은은하게»를 너무 낮게 잡기 쉽다** — 첫 판 불투명도 0.10~0.42 는 «안 보일 지경»이었다. 0.22~0.60 에서 받아들여졌다.

## 다시 만드는 법
- 도구(경로로 부른다): `../../jobs/2026-10_학교포스터/work/` 의 `ascii.py`(문자 아트 레이어), `cells.py`(네모 칸 배치·서체 비교판), `layers.py`(그림 → 판 크기 레이어), `build_psd.jsx`·`build_psd.py`(포토샵 조립), 값은 `spec.py`. 그림이 3D 조형물이면 `scene_inf.py`(Blender) 를 본보기로.
- 바꿔 넣을 것: 그림(투명 배경 PNG 한 장이면 된다, `layers/sculpt.png` 자리), 글자(`LEFT`·`RIGHT`·`TAG` 의 glyphs), 색 다섯(`ASCII`), 배경 문자 비(`ASCII.rain`).
- 명령: 새 건 폴더에서 `python -m forge init` 뒤 위 스크립트를 경로로 부르는 단계로 `pipeline.json` 을 짜고 `python -m forge run <건>`. 🔴 이 결을 두 번째 건에서 쓰게 되면 `ascii.py` 를 `forge/lib` 로 올리고 이 칸의 경로를 고친다(README §쓰는 법 5).
