# STYLE — 액체 크롬

> **뭐냐:** 판 전체를 출렁이는 액체 금속(크롬) 표면 하나로 채운 결. 몸은 검정과 흰색 사이의 부드러운 반사 그라데이션이고, 등성이마다 아주 얇고 또렷한 흰 반사 테가 돌며, 몇 군데에만 무지개 테와 무지개 동심원 점이 박힌다. 무채색이 약 80%, 색은 5% 안팎의 포인트뿐이다.
> **언제 읽나:** 사람이 «크롬으로», «리퀴드 메탈», «그 은색 출렁이는 느낌으로», «Y2K 금속» 이라고 할 때. 시작 전에 끝까지.
> **안 담는 것:** 표현 방법 손잡이·함정 → `../../techniques/액체_크롬_반사.md` · `../../techniques/무지개_테.md` · 레퍼런스 원본과 숫자(남의 것, 깃에 안 올림) → `../../refs/_모음/포스터_그리드/36_liquid_chrome/`.

대표 그림 없음. 레퍼런스는 남의 것이라 여기 두지 않는다. 원본·확대판(`z1_무지개테` · `z2_색점` · `z3_가운데` · `z4_왼쪽노랑`)은 `../../refs/_모음/포스터_그리드/36_liquid_chrome/` 에 있다.

## 언제 쓰나 / 안 맞는 곳
- 쓰나: 폰 배경화면·스토리·릴스(9:16), 음악·공연·패션·뷰티·테크 행사의 바탕, 글자가 거의 없거나 굵은 제목 하나만 얹는 판, 실험적이고 차가운 분위기.
- 안 맞음: 기업·관공서 손님(본 사이트 손님층은 «mz틱» 금지, `protocols/promo.md` §공통), 정보가 많은 공지(흰 테가 판 전체를 지나가 작은 글이 묻힌다), 따뜻하고 차분한 행사.

## 결을 정하는 값 (레퍼런스 1125×2000 실측, 2026-10-23)
| 무엇 | 값 | 비고 |
|---|---|---|
| 판 | 세로 9:16, 형태가 판 사방에서 잘림 | «가까이서 본» 결. 무게중심 (50%, 51%), 판 전체에 고르게 |
| 색 | 무채색 78.7%. 검정 `#222021` 31.1% · 흰색 `#F6F9F7` 26.4% · 진회색 `#403D3B` 13.6% · 회색 `#787169` 7.6% | 크롬은 «회색»이 아니라 검정과 흰색이 거의 반반 |
| 차가운 반사 | 파랑 회색 `#94A9BA` 6.6% · `#4F5F77` 5.4% | 하늘(환경)이 비친 색. 차가움 12.6% 대 따뜻 8.6% |
| 따뜻한 반사 | 베이지 `#C7B6A1` 5.7% · 구리 `#AA5E39` 1.6% | 살색 덩어리 하나(판 가운데 아래)가 유일한 따뜻한 면 |
| 강한 색 | 채도 0.5 넘는 곳 4.86% 뿐: 무지개 테·동심원 점·왼쪽 가장자리 노랑 `#EBE68B` | 🔴 색은 «포인트»다. 넓히면 결이 무너진다(추정) |
| 명암 | 어두움 37.9% · 중간 32.5% · 밝음 29.6%, 그중 하얗게 날아간 곳 18.7% | 골유리 모노크롬(흰색 0)과 정반대로 흰색을 아낌없이 날린다 |
| 흰 테 | 밝은 덩어리 가로 길이 중앙값 10px(판 폭 0.9%), 25~75% 구간 4~35px | 얇은 테가 대부분, 넓은 흰 면은 적다 |
| 모양 | 곡선 86% · 직선 14%, 경계 방향 사선 76%, 자유곡선 덩어리 87% | 구멍 뚫린 막, 늘어난 고리, 흘러내린 줄기 |
| 초점 | 고르지 않음: 아래 왼쪽·왼쪽 가장자리 크게 흐림, 가운데와 오른쪽 아래 테는 또렷 | 얕은 피사계 심도(추정) |
| 글자 | 없음 | 얹는다면 큰 검정 면 위에 흰 굵은 산세리프 하나(미검증) |

## 다시 만드는 법 (미검증, 재현 시험 전)
- 3D 길: 블렌더에서 평면을 잘게 나눠 노이즈 두 겹(큰 출렁임 + 중간 구멍)으로 밀어 올리고, 금속 1·거칠기 0.02 안팎, 하늘과 바닥이 대비 큰 HDRI 하나(사람 사진 한 장을 섞으면 살색 덩어리가 생긴다). 카메라를 표면에 바짝, 조리개를 열어 가장자리를 흐린다. 렌더 순서는 `protocols/modeling.md` 와 `TOOLS.md` 의 블렌더 줄.
- 2D 길: 노이즈 높이 지도 → 법선 → 반사 방향으로 환경 그림을 집어 오기(numpy). 도구는 아직 없다(`ad/` 에 올리면 이 줄을 고친다).
- 색 포인트: [무지개 테](../../techniques/무지개_테.md) 를 테 두세 곳, 동심원 점 한두 곳에만.
- 점검: 레퍼런스 확대판 넷과 같은 배율로 나란히 놓고, 흰 테 두께(판 폭 0.9% 안팎)와 강한 색 넓이(5% 안팎)를 잰다.
