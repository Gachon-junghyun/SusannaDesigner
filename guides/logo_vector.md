## 1. 작업 판을 세운다 (안이 여럿이면 «한 안 = 한 작업자»)

**해라**
- 안마다 폴더 하나: `final/<안>/` — 원안 PNG 경로, 결과물(svg · .ai · `_CS6.ai` · `preview.png` · `preview_선만보기.png` · `zoom_*.png` · `NOTES.md`), 중간물은 `_work/`.
- 안이 셋 이상이면 **하나는 내가, 나머지는 에이전트**(§에이전트). 크롬·일러는 한 대뿐이라 **잠금을 먼저 깐다**:
  `python kit/logo_vector/lock.py img -- <그림 뽑기 명령>` · `python kit/logo_vector/lock.py illu -- <일러 COM 명령>`.
- 일러가 꺼져 있으면 **COM 전에 `Start-Process` 로 띄우고 창 제목을 확인**한다(COM 이 띄우면 창 없이 멈춘다).

**통과**: 잠금 둘이 서로 막는지(`lock.py img -- python -c "import time;time.sleep(5)"` 를 두 창에서) 한 번 본다.
**왜**: 크롬 다운로드 폴더는 **탭마다가 아니라 크롬 전체 설정**이라, 제미나이와 ChatGPT 를 동시에 돌렸더니 제미나이 원본 2장이 ChatGPT 폴더로 샜다(2026-10-10). 잠금을 깐 뒤 작업자 셋이 2시간 돌면서 충돌 0.

## 2. 글꼴부터 대 본다 — «상용 글씨를 찾고 없으면 뽑는다»(사람 지시)

**해라**
- 후보는 **라이선스 원문이 있는 것만**: 구글 폰트 OFL(`github.com/google/fonts/tree/main/ofl/<폴더>/OFL.txt` 를 받아 확인) · 눈누(`noonnu.cc/font_page/<번호>` 의 표 — **인쇄 + BI/CI 칸이 둘 다 «사용 가능»**이어야 로고에 쓴다).
- 결이 비슷한 후보 5~10개를 **원안과 같은 배치**(음절 위치·크기 그대로)로 찍어 원안 옆에 한 장으로 놓는다(`예시_세로현판/fontcmp.py`). 그림을 `_font_compare.png` 로 남긴다.
- 판정 기준 셋: ① 획 굵기 대비와 끝 모양(둥근 캡슐인가, 깎인 붓인가) ② 맞춤 배치를 넣었을 때 비율이 틀어지나 ③ 받침·쌍자음이 붙거나 떨어지나.

**통과**: «이 글꼴을 쓴다(라이선스 URL)» 또는 «안 쓴다, 이유 한 줄 + 비교 그림».
**왜**: 세 안 모두 글꼴로는 안 됐는데, 이유가 각각 달랐고 **그림이 없으면 «왜 글꼴 안 썼냐»에 답을 못 한다**.
· 도장 격자: «세로로 긴 상» 같은 맞춤 배치에 글꼴을 늘리면 획이 틀어진다. 결이 가장 가까운 주아체는 끝이 둥근 캡슐(사람이 «캡슐 같다»로 이미 되돌린 결).
· 세로 현판: 붓 글꼴 5종이 «굵고 끝이 깎인 붓맛»을 못 낸다(나눔붓은 가늘고, 독도는 뭉툭).
· 한지 반전: 동해독도는 마른 붓 찢김 + «근»의 ㄴ 이 떨어짐. 눈누 잉크립퀴드체는 결은 가깝지만 **BI/CI 사용 금지** → 로고 불가. 양진체는 BI/CI 가능이지만 붓이 아니다.
⚠️ 라이선스가 사이트마다 다르게 말하면(KCC간판체 — 공유마당·눈누·폰트 파일이 셋 다 다름) 쓰지 않는다.

## 3. 원안을 고해상으로 «그대로» 다시 그린다

**해라**
- `python kit/logo_vector/lock.py img -- python -m ad redraw <원안.png> --out <폴더> --engines chatgpt,gemini --change "<지킬 것 + 바꿀 것 딱 하나>"`.
  `--change` 는 **지킬 것을 부품별로**(글자 배치·획 모양·지붕·솥·바탕) 적고, 바꿀 것은 «잔선을 한 면으로» 같은 **한 가지만**.
- 글자가 문제면 **글자 칸만 흑백으로 떼어** 다시 그리게 한다(세로 현판). 배경·장식과 같이 주면 엔진이 장식을 «고쳐» 넣는다.
- 두 엔진 판을 나란히 놓고 **부위별로** 좋은 쪽을 고른다 — 한 판을 통째로 쓸 필요 없다(세로 현판: 글자는 제미나이, 지붕은 ChatGPT, 솥은 제미나이).
- 2차가 필요하면 «테두리 혹·찢긴 붓끝·획 속 틈만 정리»처럼 **정리만** 시키고, 획이 가늘어지지 않았는지 잉크 면적 비율로 잰다(한지 반전: 0.353 → 0.368 이라 통과).

**통과**: 철자 음절별 눈 확인 · 원안과 겹쳐(IoU) 배치가 그대로(세로 현판 음절별 0.91~0.94) · 새로 «지어 넣은» 것 없음.
**왜**: 원안(1~2천 px)을 바로 따면 확대 시 잔물결이 남는다(고객H 때 이미). 엔진은 «고쳐 주려고» 지어 넣는다 — 제미나이가 지붕 밑에 없던 크림 띠를 그렸고, 원안 솥 옆 도장 속 글자는 «천/첟» 같은 깨진 잡글자였다 → **빼고 사람에게 물었다**.

## 4. 색별로 따고, 기하는 «다시 세운다»

**해라**
- 업스케일(`ad upscale` 또는 `ad retrace` 가 남기는 `<이름>_x4.png`) → **`kit/logo_vector/multitrace.py <x4.png> <out.svg> --split-red --close 16`**.
  팔레트(빨강 · 크림 · 먹 · 흰)를 정하고 **색마다 따로 potrace**, 칠은 단색만, 흰 바탕 네모는 넣지 않는다.
- 🔴 **빨강은 «붉은 기가 확실한 픽셀»만**(`r − max(g,b) > 60`). 나머지 경계 픽셀은 먹·크림·흰 중 가까운 쪽으로.
- **사람 손으로 그은 듯한 기하는 따지 말고 다시 세운다**: 바탕 네모(정확한 직사각형) · 틀(다각형, 두께 고정) · 좌우 대칭물(왼쪽 반을 거울로) · 반복물(기와: 가운데 몇 장을 평균해 **한 장** → 같은 간격으로 복제).
- 겹치는 색은 **«구멍 뚫린 판» 대신 «통 실루엣 위에 얹기»**(세로 현판: 검정 지붕 실루엣 + 그 위 크림 기와).
- 그룹 이름을 부위별로(`board · roof · letters · cauldron · line`) — 일러에서 그대로 그룹이 된다.

**통과**: SVG 칠 색 = 팔레트 수 · 그라디언트 0 · 흰 바탕 네모 0 · 그룹이 부위별.
**왜**:
· 🔴 `ad retrace` 는 **한 색만** 따고 3단 그라디언트를 건다 → 도장 격자 첫 판에서 크림 바탕과 검은 처마선이 통째로 빠졌다.
· 🔴 «가장 가까운 색»만 쓰면 **먹↔크림 경계의 회색이 빨강으로** 가서 검은 선 밑에 가는 빨간 조각이 숨는다 — 칠한 그림엔 안 보이고 **선만 보기에서 겹선**(사람이 말한 «CS6 에서 줄 깨짐»의 정체 중 하나). 규칙을 넣자 글자 윤곽이 11 → 9 로 줄었다.
· 손 그은 기와는 간격 80~97 · 각도 제각각이라 따면 들쭉날쭉이 그대로 남는다(한지 반전). 틀 좌우 높이도 원안은 달랐다.

## 5. 확대해서 «하나하나» 고친다

**해라** — 벡터를 **3000px 이상**으로 그려 음절·부위별 `zoom_*.png` 로 잘라 전부 연다. 볼 것과 고치는 법:
| 본 것 | 고치는 법 | 근거 |
|---|---|---|
| **바늘 끝**(끝에서 8px 지점 굵기 < 주 획의 1/4) | 그 **구역만** 지름 ≈ 주 획×0.27 원으로 «열기»(꼬리 제거) → 획 방향 타원 «닫기»(빠진 홈 메움). 벡터를 불리지 마라 | 세로 현판 4곳(상 ㅅ 왼끝 · 근 ㅡ 실꼬리 · 근 ㄴ 끝 · 이 ㅣ 밑) → 전부 1/4 위 |
| **바늘 틈**(솥 테 밑, ㄱ 아래 홈) | `--close <반지름>` — 실제 크기에서 «못 깎는 폭»(≈4mm)만 메우게 반지름을 잡고, **바뀐 픽셀을 색칠한 diff 그림**으로 확인 | 도장 격자 `--close 16`(4800px 판 = 600mm 기준 4mm) |
| 닫기를 크게 걸었더니 **다른 자모가 붙음** | 반지름을 줄인다 | 한지 반전: 30 → «근»의 ㄴ 이 ㅡ 에 붙음 → 12 |
| 꼬리 뺀 자리에 생긴 **계단** | 양옆 기울기를 맞춘 곡선으로 이어 «더하기만» | 세로 현판 근 ㅡ 아랫면 6px |
| ㅇ 속 **뾰족한 꼭지** | 작은 반지름으로 둥글게 | 세로 현판 이 |
| **열린 고리**(붓길이 감기는 ㅇ) | **닫지 마라** — 원안부터 디자인 | 세로 현판 상 |
| 거의 수직인 테두리의 **물결** | 너무 키워 따지 마라 — 원 해상도로 내려 potrace 허용치(0.4)에 맡기니 한 줄로 폈다 | 세로 현판 3배 판 |
| 붓 «혹·톱니·찢긴 끝» | 래스터에서 «열기 r ≈ 획의 1/4» + 작은 닫기 + 흐림 후 다시 따기 | 한지 반전 |

**통과**: 선 끝 굵기 전부 주 획의 1/4 이상(`예시_한지반전/tipcheck.py`) · 티끌 0 · 막힌 속공간 0 · 철자 그대로.
**왜**: 사람이 «미음새나 디테일 하나하나»를 짚었다. 숫자 검사만 하면 «열린 고리»를 닫아 버리고, 눈만 보면 바늘 끝을 놓친다 — 둘 다 한다.

## 6. «선만 보기»로 검수한다 — 사람이 말하는 «줄 안 깨지게»

**해라**
- SVG 의 칠을 `fill="none" stroke="#000"` 으로 바꾼 그림을 그려 **선만 보기(Ctrl+Y)를 재현**하고(`preview_선만보기.png`), 선 끝·겹치는 곳을 크게 잘라 본다.
- 볼 것: ① 한 테두리가 **두 줄**로 보이는 곳(숨은 조각) ② 같은 줄이어야 할 테두리가 **꺾이거나 층**진 곳 ③ 떨어져 나온 작은 조각.
- 곡선끼리 잇는 마디의 접선 꺾임을 잰다(`예시_한지반전/joints.py`) — 0.3° 이하면 매끈.
- 🔴 **둥근 붓 글씨엔 `ad straighten` 을 쓰지 마라.** 쓰려면 사본에 돌려 **전후 픽셀 diff** 를 먼저 본다.
- potrace 가 «평평한 직선 + 급한 곡선»으로 나눈 처마·호는 **포물선(곡선) 하나로** 다시 맞춘다(원래 선과 차이 0.4pt 이하).

**통과**: 겹선 0 · 꺾임 0(직선 모서리 제외) · 떨어진 조각 0.
**왜**: 칠한 그림은 멀쩡해 보여서 사람 눈에 «AI 가 고쳤다»가 안 보이고, 일러를 여는 순간 들킨다. `straighten` 은 셋이 따로 돌려 **셋 다 버렸다** — 이 ㅇ 속이 곧은 세로선으로 펴지고(도장 격자·세로 현판), ㄴ 모서리가 네모가 되고, 세로획 붓맛이 사라졌다(한지 반전).
⚠️ 선만 보기에서 **크림 바탕 테두리가 위 색 밑으로 지나가는 것**은 «얹기» 구조라 정상이다 — 같은 모양이 두 번 겹친 패스와 구별해서 사람에게 미리 말한다.

## 7. 일러로 굽는다 — CC 와 CS6 두 벌

**해라**
- `python kit/logo_vector/lock.py illu -- python kit/logo_vector/save_cs6.py <in.svg> <out.ai> --cc` (CC = ILLUSTRATOR17)
- `python kit/logo_vector/lock.py illu -- python kit/logo_vector/save_cs6.py <out.ai> <out_CS6.ai>` (기본 = **ILLUSTRATOR16 = CS6**, 글자는 윤곽선으로)
- 점검 둘: ① 파일 머리 `%%Creator: Adobe Illustrator(R) 16.0` ② 일러로 열어 센다 — 대지 · 패스 · **그라디언트 0 · 클리핑 0 · 글자 0 · 이미지(placed/raster) 0** · 색 목록(`예시_*/inspect_ai.py`).
- 세 파일(SVG · CC · CS6)을 같은 배율로 그려 픽셀 차이 0 인지 본다(세로 현판에서 0).
- 실제 크기를 가정해 `python -m ad fabcheck <svg> --h <mm> --min <mm>` — 가장 가는 곳·뾰족한 끝. 가정은 «(가정)»이라고 적는다.

**통과**: 위 점검 전부 + `preview.png` 를 **CS6 .ai 에서** 그린다(원본 SVG 말고).
**왜**: `save_cs6.py` 는 성공해도 `undefined` 를 찍는다(DoJavaScript 가 try/finally 의 값을 못 돌려줌) — **출력 말고 파일 머리로 확인**한다. 일러 COM 은 **내가 연 문서만** 닫는다(`try/finally`) — 사람 문서를 저장 없이 닫은 이력이 있다.

## 8. 묶어서 보낸다 — 사람은 PC 앞에 없다

**해라**
- 안이 여럿이면 한 파일로: `lock.py illu -- python -m ad board a.svg b.svg c.svg --labels "1|2|3" --out <묶음>` → 대지 여럿 .ai + PDF + 미리보기 → 그 .ai 를 다시 `save_cs6.py` 로 CS6.
- 폰으로 **파일 자체**를: `module_voice.push_file(<CS6.ai>, caption, bot='<도메인 봇>')` · PDF 도 따로(사람이 «pdf 로도»라고 바로 요구했다) · 미리보기는 `push_photo`. 반환 `None` = 성공.
- 구글 드라이브는 `G:\내 드라이브\…` 에 **복사**(MCP 로 올리지 않는다).
- 끝난 안부터 먼저 보낸다 — 셋 다 기다리지 않는다.

**통과**: 텔레그램에 .ai · .pdf 가 첨부로 와 있다.

## 에이전트 역할

- **안 하나 = 에이전트 하나.** 프롬프트에 넣을 것: 원안 경로 · 결과 폴더 · 결과물 목록(svg · CC · CS6 · preview · 선만 보기 · zoom · NOTES) · 2단계 글꼴 규칙 · 이 가이드 경로 · **잠금 규칙(그림 뽑기·일러 둘 다)** · «남의 문서·탭 건드리지 마라» · «폰 전송·커밋 하지 마라(조정자가 한다)».
- 🔴 **조정자가 먼저 밟은 함정은 그 즉시 `SendMessage` 로 돌린다.** 이번에 «retrace 는 한 색만 · 숨은 빨간 조각 · straighten 금지»를 중간에 보냈고, 두 에이전트 다 반영해 같은 함정을 안 밟았다(세로 현판은 straighten 을 사본에만 돌려 확인 후 버림).
- 에이전트 보고는 **모델 출력**이다 — 조정자가 `preview.png`·`preview_선만보기.png` 를 직접 열고 CS6 머리를 직접 확인한 뒤에 보낸다.
- 걸린 시간(실측): 조정자(도장 격자) ≈ 35분 · 에이전트 세로 현판 ≈ 32분 · 한지 반전 ≈ 100분(기하 재건축·기와 복제·마디 각도까지 해서 가장 길었다).

## 아직 모르는 것

- **실제 CS6 프로그램에서 열면 어떤가** — 이 PC 엔 2026 만 있다. 파일 머리·구성으로만 확인했다. CS6 가 있는 PC(대표님 쪽?)에서 한 번 열어 보면 «확인함»이 된다.
- **Ctrl+Y 를 일러 화면에서 직접** — 지금은 SVG 를 선으로 그린 재현이다. 일러 COM 으로 선만 보기 화면 캡처가 되나?
- **CMYK·별색** — 전부 RGB 문서다. 출력소 프로파일·교정 전에는 값을 적지 않는다(P6).
- **실제 크기·시공 방식** — 크기를 «가정»해 fabcheck 만 했다. 채널이면 처마선 같은 가는 부위는 안 된다(절곡 38mm).
- 붓 글씨 테두리의 «잔물결»을 사람이 «울퉁불퉁»으로 볼지(한지 반전은 젖은 붓 느낌을 살려 일부 남김).
