## 1. 레퍼런스를 «직접 열어» 본다

**해라**
- 크롬 9222 에 **자기 탭**을 새로 열고, CDP `Emulation.setDeviceMetricsOverride` 로 **1440·375** 두 폭을 찍는다. 같은 탭에서 `getComputedStyle` 로 글꼴·크기·굵기·글자색·면색·모서리·테두리·max-width 빈도를 한 번에 뽑는다(design-md-chrome 확장이 뽑는 값과 같다 — 확장은 사람이 로드해야 하니 에이전트는 eval).
- 사이트 사이 3~9초 무작위 대기 + 무작위 스크롤을 **처음부터** 넣는다(메모리 `browse-random-delays`).
- 어디서 고를지 막막하면 심부름 지도 `site_map.json` 의 `design_moodboard`(Httpster 웹 갤러리 · Typewolf 서체 식별 · The Brand Identity 등 일곱)부터 연다.
- 10곳 남짓 보고 `runs/<날짜>_<이름>/REFS.md` 에 «가져올 것 한 줄 · 버릴 것 한 줄»로 적는다.
- 🔴 로그인된 9222 라 **스크린샷에 계정이 찍힌다**(퍼플렉시티 옆줄 대화 목록, 네이버 이름). 밖으로 보낼 땐 잘라라.

**통과**: 사이트마다 `desk_1440.png`·`phone_375.png`·`tokens.json`.

**왜**: 검색 요약으로 고른 레퍼런스는 이름만 남는다(메모리 `design-no-ai-look`). 금융 건에서 «요약 피드»의 원형이 네이버 «AI 브리핑»과 퍼플렉시티 «시장 요약»이라는 건 직접 열어 보고서야 나왔다.

## 2. 방향 셋을 그림으로 보낸다

**해라**
- 레퍼런스를 묶어 방향 셋(예: 브리핑 데스크 · 신문 지면 · 단말기)을 만들고, 방향마다 레퍼런스 두 장을 **잘라 붙인 한 장**(PIL) + 한 줄 개념으로 결재 봇에 보낸다. 추천 하나를 적는다.
- 답을 기다리는 동안 **방향과 무관한 것**(데이터 연결·뼈대·화면 구조)을 짓고, 색·글꼴은 토큰으로만 둔다 — 방향이 바뀌면 토큰만 간다.

## 3. 토큰과 단일 원본 `DESIGN.md`

**해라** — 줄마다 출처를 단다.
- 색: 바탕 하나 · 먹 하나 · 한 계열 명도 단계. 면은 선이 아니라 «한 단 내린 톤»으로 가른다(TasteSkill).
- 글자 크기 **다섯 단계**까지(작은 글 14 · 본문 16~17 · 소제목 · 리드 · 제목). 본문은 16px 아래로 두지 않는다.
- 간격·모서리 단계는 `design-md/` 한두 장(금융이면 wise·mercury)에서 «숫자만» 가져온다. 브랜드는 안 베낀다.
- 숫자 색(오름·내림)은 `ui-ux-pro-max` «Color Only» — 색만으로 말하지 말고 부호를 같이.

## 4. 화면을 짓는다

**해라**
- Next 사이트는 `HOMEPAGE_MAKER/templates/nextjs-susanna-stack` 복사 → 자기 git → `wrangler.jsonc` 에 **account_id 를 박는다.**
- 첫 화면은 «방문자의 첫 물음»에 큰 글자로 답한다. 데이터가 낡았으면 **낡았다는 사실을 문장으로** 말한다(옛 문장을 오늘 것처럼 세우지 않는다).
- 신선도 한 줄을 모든 화면에.
- 공개 문구에 가운뎃점·긴 줄표·이모지 금지(메모리 `no-middle-dot-in-copy-text`).

## 5. 검사기를 돌린다 (TasteSkill)

```bash
node <aidesigner>/.claude/skills/taste-skill/scripts/lint.mjs app components
node <aidesigner>/.claude/skills/taste-skill/scripts/inspect.mjs http://localhost:<port>/
```
- FAIL 은 고친다. 지키는 경고·FAIL 은 `DESIGN.md` 에 한 문장씩 근거를 적는다(예: 숫자 사이트의 «그림 0장»).
- 그다음 **스크린샷을 직접 보고** 고칠 셋을 고른다(검사기 통과 ≠ 좋음).

## 6. 움직임 (Design Motion Principles — audit)

- 프로젝트 종류로 가중을 고른다(읽는 금융 사이트 = Emil 주 · Jakub 부).
- `references/anti-checklist.md` 로 pulse·blur 등장·hover-scale·스태거 남발을 본다. 스태거는 한 목록에만, 자주 여는 화면이면 상한을 짧게(금융 건: 5칸 × 70ms).
- `prefers-reduced-motion` 은 예외 없이.
