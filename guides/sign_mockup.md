## 1. 받기 — 메일·톡클라우드·현장 사진

**해라**
- 카톡 내보내기 메일 첨부는 메일 탭에서 `disp=safe → disp=attd` 로 바꿔 `fetch` 로 받는다.
- 톡클라우드 2단계 인증은 **«이메일로 인증하기» + Gmail 검색**으로 사람 없이 통과한다(«이 브라우저에서 2단계 인증 사용 안 함»은 누르지 않는다).
- 사진·파일은 목록 API 로 방·시각을 고르고 링크 클릭으로 받아 **크기(int)로 대조**한다.
- 손님 `.ai` 는 **일러로 열어 대지를 그림 전체로 넓혀 내보낸다** — 대지 밖까지 그려 놓는 일이 많다(고객J: A4 대지 밖으로 띠 두 줄). 색공간(CMYK)·글자 수·그림 수를 적는다.

**통과**: 받은 개수·크기 일치 · 손님 파일 전체 그림을 눈으로 봤다.
**왜**: 손님 .ai 를 fitz 로만 열었더니 대지(A4)만 그려져 글자가 반쯤 잘려 보였다.

## 2. 판독 — 스케치·색·치수·현장 로고

**해라**
- 🔴 **스케치의 선·화살표·메모를 하나도 빼지 말고 «무엇을 가리키나» 표**로 짝짓는다: `선/표시 | 가리키는 것 | 해석 | 확실/추정`. 짝 없는 선(특히 글씨 위·아래 가로선)은 조명바·띠·테두리 후보로 두고 묻는다.
- 치수는 **쓴 숫자**를 따른다(손 그림 사각형 비율은 축척이 아니다 — 7.4 vs 쓴 숫자 5.818).
- 도료 색 견본 사진은 **같은 사진 속 흰 카드로 흰 균형 + 먼셀 명도로 밝기**를 맞춰 화면색을 낸다(노루 MD 6126 → #456655, 측정 Y 0.1176 vs 먼셀 0.1136).
- 현장 로고가 바랬으면 **카카오맵 업체 페이지 로드뷰 미리보기 src 의 `…_cube/left_2048.jpg`**(옛 연도 2048²)로 원래 색을 찾는다.
- 현장 «자리» 치수는 3D 측정(4단계)에서 받는다. **옛 간판 길이를 새 간판 길이로 가정하지 마라.**

**통과**: 표의 모든 줄이 결과물 체크리스트가 됐다 · 추정 줄은 사람에게 물을 목록에 있다.
**왜**:
- 글씨 아래 가로선 + «빨간» 화살표(= **빨간 바조명**)를 «로고 빨강»으로 읽고 통째로 빠뜨렸다. 사람이 스케치를 잘라 보여 주며 크게 화냈다.
- 옛 빨간 띠 = 6,400 으로 가정한 합성은 3D 측정(7.9m) 대비 **간판을 23% 크게** 그렸다.
- «로고가 헐어서 그런 거지 원래 더 선명했을 것» — 2011 로드뷰에 파란 아치·청록 띠·초록 잎이 있었다.

## 3. 글꼴 — 레퍼런스 → 게이트 → 후보 → 적용

### 3-1. 레퍼런스부터 직접 본다
**해라**
- 네이버 이미지 검색 **세 개 이상**(«공인중개사 간판», «부동산 채널간판», «… 간판 고급»)을 탭을 앞으로 띄운 채 천천히 스크롤해 모은다. 썸네일은 **원래 주소(type=a340) 그대로** 받는다(크기 바꾼 주소는 404).
- 모은 것을 번호 붙인 모음판으로 보고 **«글씨 결» 갈래로 묶는다**(두툼한 둥근 · 붓 캘리 채널 · 굵은 기울임 · 둥근 친근 …).
- 사람이 레퍼런스 사진을 주면 **그 글자를 크게 잘라 후보 글꼴과 같은 글귀로 나란히** 대 본다.

**왜**: 설치 글꼴 10종을 먼저 내밀었다가 «다 거기서 거기, 레퍼런스 찾아». 후보는 레퍼런스 갈래에서 나와야 한다.

### 3-2. 🔴 게이트 — 후보에 올리기 «전»에 세 개 다 통과
1. **라이선스**: 눈누 상세 표에서 **인쇄 · BI/CI 가 «사용 가능»**(«조건부»는 본문을 읽는다) **+ OFL 행이 «수정 가능»**. 공공 서체는 지자체 원문 페이지까지 가서 «변형 금지»·«출처 표시» 문구를 캡처한다.
2. **채널 제작 가능**: 상호 글자를 실제 크기로 찍어 **붙은 자모가 없나**(도 ㄷ·ㅗ, 시 ㅅ·ㅣ…) · 가장 가는 획이 채널 최소폭 이상인가 · 속공간이 막히지 않나.
3. **결이 레퍼런스와 맞나**: 같은 배치 비교판에서 사람이 고른 결(«1번처럼 깔끔한»)을 지키나 — 붓이어도 날림·장식 과한 것은 뺀다.

**통과**: 후보마다 «라이선스 URL · 붙은 자모 0 · 결 한 줄»이 적혀 있다. 하나라도 빠지면 후보에서 뺀다.
**왜**: 가평 한석봉 큰붓을 골랐는데 조건이 **«원본 글씨 형태의 변형 없이»**였고, 채널을 만들려면 «도»의 ㄷ·ㅗ를 띄워야 했다 → 띄우자 사람이 «상업적으로 얼마나 디테일해야 하는지 모른다, 그 폰트는 못 쓴다». **게이트를 고른 뒤에 봐서** 렌더·AI 까지 다 돈 뒤에 버렸다.

### 3-3. 출처 표시(공공 서체를 쓸 때)
- 저작권법 제24조의2(공공저작물 자유이용)로 쓰더라도 **제37조 출처 명시 의무**가 붙는다(예외 목록에 24조의2 없음). 방법은 «이용 상황에 따라 합리적인 방법». 문체부 「공공저작물 저작권 관리 및 이용 지침」 제20조도 같다.
- 간판 예시는 원문에 없다(가평군은 인쇄물 예시만, 대구 중구는 «간판 가능, 출처표기 권장»). **간판 쓰기 전에 그 지자체 담당 부서에 «간판에 어떻게 표시하나»를 사람이 묻는다.**
- 글자체 디자인 자체는 판례상 저작물이 아니고 폰트 파일이 프로그램으로 보호된다(대법원 94누5632 · 99다23246, 한컴 공지의 문체부 답변). 그래도 **배포처 사용 조건(변형 금지 등)은 라이선스 문제로 남는다** — 3-2 게이트에서 거른다.
- 근거 원문: `DeGaJa_Agent/users/…/2026-10_부동산/refs/license/`.

### 3-4. 적용 — 손님 배치에 서체만 바꿔 끼운다
**해라**
- `font_variants.py <손님 띠> <글꼴.ttf>`: 손님 글자의 **아랫선·왼끝·높이**에 맞추고, 넓으면 전화번호와 60mm 띄울 만큼 줄이고, 좁은 붓은 700mm 안에서 채운다. 자간 0.04H.
- 🔴 **글꼴 윤곽을 먼저 합친다**(`pathops simplify`) — 겹친 윤곽(나눔스퀘어라운드 «도»)은 블렌더에서 구멍이 된다.
- 전화번호·작은 글자 서체를 같이 바꿀지 사람에게 묻는다(기본은 손님 것 그대로).

**통과**: 비교판에서 음절마다 확대해 봤다 · 원본 상자와 높이·아랫선 차이가 적혀 있다.

## 4. 일러스트 파일 — 1:10 CS6

**해라**
- 6,400mm 는 일러 대지(약 5,779mm)를 넘는다 → **1:10**(640×110mm). 파일명에 `1대10`.
- 바탕·라인·전화·흰 글자는 **손님 벡터 그대로**, 바꾼 것만 갈아 끼운다(`build_ai.py`). 그룹 이름을 부재 이름으로(바탕_녹색_노루MD6126 · 상단_라인박스 · 고객J_채널 · 전화_채널 · 스카시_흰색 · 하단_바조명).
- `save_cs6.py` 는 성공해도 `undefined` 를 찍는다 → **파일 머리 `Adobe Illustrator(R) 16.0`** 로 확인. 일러로 다시 열어 **대지 mm · 클리핑 0 · 글자 0 · 그림 0 · 색 목록**을 센다(`inspect_ai.py`).
- **정렬을 숫자로 잰다**: 덩어리 아랫선 하나(오차 ≤ 0.5mm) · 오른끝 맞춤. 띄어쓰기 폭을 두 군데서 다르게 계산해 «대표 최은희»가 3.6mm 튀어나왔던 적이 있다.
- 비율 점검표를 돌린다(PNG·SVG·PDF·CS6·3D 상자 전부 6,400:1,100 = 5.8182, 오차 0%).
- 색은 RGB 로 나간다 — 출력소 CMYK 는 «따로 맞춰야 함»이라고 적는다.

**통과**: CS6 머리 16.0 · 이미지 0 · 클리핑 0 · 정렬 실측 · 비율표 통과.

## 5. 3D 모델링·렌더 — 간판은 «부재»로 짓는다

### 5-1. 건물
- [`modeling.md`](modeling.md) 1~9단계 그대로(사진 셋 동시 맞춤, 축척은 문짝 2.10m 가정 ±15%). 간판 자리 폭·높이를 숫자로 낸다.
- 🔴 카메라 rms 가 낮아도(1.95px) **긴 수평선 기울기는 따로 잰다** — 위·아래 변이 반대로 0.4° 틀어져 «살짝 삐뚠» 간판이 나왔다. `fix_tilt.py` 로 위(2층 띠 아랫선)·아래(옛 띠 아랫선)에 사영 보정.

### 5-2. 🔴 간판 부재 — 평면 그림을 판에 붙이지 마라
| 부재 | 짓는 법 | 밤 |
|---|---|---|
| 불 들어오는 글자 | **채널**: 옆면·앞테(노란 도장) 깊이 80mm + 앞판(아크릴) 앞테 4mm 안쪽 | 앞판만 발광 0.9 |
| 불 안 들어오는 글자 | **스카시**: 아크릴 10mm | 불 없음(손님 확인) |
| 상단 라인 | **라인박스 «앞면»이 빛줄로 빛난다**(태평한우 결 — 아래로 쏘지 않는다). 박스 100mm 돌출 + 앞면 발광판, 색 `LINE_RGB=1.0,0.50,0.06` · 세기 `--downled 2.2` · 글레어 `--glare 0.9 --glarestr 0.45` | 판은 어둡게 두고 라인 둘레만 은은한 번짐. 레퍼런스 빛줄 색 240·192·98 ↔ 렌더 249·192·117 |
| 판 | 녹색 도장(노루 색), 밤엔 코팅 0·거칠기 0.65 | 가로등이 흰 점으로 비치지 않게 |
- 글자 벡터는 색별 mm SVG → 블렌더 커브 → 압출. **SVG 네 귀에 1mm 표식**을 두고 그것으로 축척을 재서 점을 직접 옮긴다(오브젝트 스케일 금지 — BLENDER.md ⑫·⑱).
- 라인 색은 사람이 말한 대로 하나만(«노란색»). 단어(«주광색»)와 보낸 사진이 다르면 **사진 쪽으로** 하고 물어본다.

**왜**: 처음엔 손님 그림을 판 텍스처로 붙였다 → «채널이라 입체, 스카시도 튀어나온다, 블렌더 따라가라 했잖아». 라인은 «아래로 쏘는 다운라이트»로 지었다가(300W 연두 → 40W 그라데이션) 사람이 «아래가 아니라 앞으로, 태평한우처럼»으로 정정 — **레퍼런스 사진의 빛이 어느 방향인지 먼저 보고** 짓는다. 앞면 발광이 세면(8~18) 크림색으로 하얗게 탄다 → 채도 높은 호박색 + 세기 2.2 로 레퍼런스 색과 숫자로 맞춘다.

### 5-3. 렌더·합성
- 낮: `after`(그림자 받이) + `mask` → `composite.py`(벽 색 비 k 로 노출) → `fix_tilt.py`.
- 밤: 투영 재질 + `--view "Khronos PBR Neutral"`(AgX 는 빨강을 분홍으로 뺀다).
- 한 번에 하나만 렌더(GPU 하나·RAM 16GB). 설정이 바뀌면 **돌던 묶음을 바로 멈추고** 잠금 폴더·내가 연 탭을 정리한다.
