## 부탁하는 법
이 폴더에서 Claude Code 를 열고 말로 시키면 됩니다. `/design <한 줄>` 로 부르면 순서대로 돕니다.

```
/design 고객J 작업방에 새 ai 올라왔어, 두 면 시뮬하고 A4 로
/design 고객B 로고 고화질로 다시 그려서 CS6 로
/design 이 사진 양식 엑셀로
```

시작하면 먼저 **받은 자료에서 답을 찾고, 못 찾은 것만 한 번에 묻습니다**(`INTAKE.md`).
끝나면 **겪은 것을 `LESSONS.md` 에, 새로 해 본 것을 `CHALLENGES.md` 에** 쌓습니다.

## 폴더
| 무엇 | 파일 |
|---|---|
| 원칙·순서 | `CLAUDE.md` |
