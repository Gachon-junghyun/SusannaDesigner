# kit/sign_band — 손님 띠 간판 시안을 다듬는 도구 셋

> **뭐냐:** [`../../guides/sign_band.md`](../../guides/sign_band.md) 갈래가 부르는 스크립트. 고객B 삼겹살·부대찌개(2026-10-11)에서 짠 것을 그대로 옮겼다.
> **언제 읽나:** 그 가이드의 단계에서 명령을 칠 때.
> **안 담는 것:** 단계·시행착오 → 가이드 · 로고 벡터 따기·CS6 저장 → [`../logo_vector/`](../logo_vector/README.md) · 한 건의 원자료 → `DeGaJa_Agent/users/…/susanna/시안/2026-10_부대찌개/`.

| 파일 (`예시_띠간판/`) | 하는 일 |
|---|---|
| `0_톡클라우드_새파일.py` · `0_톡클라우드_받기.py` | 로그인된 톡클라우드 탭 안에서 목록 API 로 «작업방 오늘 새 파일»을 고르고, 크롬이 받게 한다(크기 대조). 앞 것이 `tcnew.json` 을 남기고 뒤 것이 읽는다 |
| `1_역할별_색바꾸기.py` | 손님 `.ai`(PDF 호환)의 그리기 단위(`get_drawings`)를 **역할별 hex**(로고 빨강·상호 빨강·띠·보조 글자·크림·먹·흰 테)로 바꿔 다시 그린다. 전화번호는 위치로 골라 띠 대비색. 안 여럿을 한 시트로 |
| `2_원판_외접원.py` | 로고 SVG 의 그림 전체를 덮는 최소 원(근사) — 원판 크기를 정하는 자 |
| `3_원판_구성.py` | 로고 부품(솥·글자·지붕·처마선)을 원판 안에 앉힌다. 구성(그대로·지붕 가운데·지붕 크게) × 색(크림 원판·빨강 원판) |
| `4_축척PDF_CS6전.py` | 간판 전체를 **1:10 벡터 PDF** 로(원판 SVG 도 그리기 단위로 같이). 다음은 `../logo_vector/save_cs6.py` |
| `5_현장시뮬_판_실제비율.py` | ChatGPT 에 줄 «현장 사진 + 간판 평면» 묶음 판·jobs, 그리고 실제 비율 그대로 붙인 합성 |

⚠️ 전부 **경로·좌표가 박혀 있다**(원본 `.ai` 의 띠 사각형 `205,212.7,944.3,250.9`, 로고 자리 `x 210~300`, 파란 표시 `x729~1165` 등). 복사해서 그 건 값으로 고쳐 쓴다.
`1_` 의 역할 표(`role()`)는 고객B `.ai` 의 hex 다 — 새 파일이면 먼저 `get_drawings` 로 색을 세고(가이드 2단계) 표부터 고친다.
