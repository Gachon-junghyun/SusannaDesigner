# kit/logo_vector — 로고 시안을 상업용 벡터로 굽는 도구 셋

> **뭐냐:** [`../../guides/logo_vector.md`](../../guides/logo_vector.md) 갈래가 부르는 작은 도구들. 손님 폴더에서 처음 짰고(2026-10-10 고객B) 다음 건이 쓰도록 여기로 옮겼다.
> **언제 읽나:** 그 가이드 1·4·7단계에서 명령을 칠 때.
> **안 담는 것:** 단계·시행착오 → 가이드 · `ad` 명령(redraw·upscale·fabcheck·board) → `../../ad/` · 한 건의 원자료 → 그 건의 `final/<안>/_work/`.

| 파일 | 하는 일 |
|---|---|
| `lock.py img\|illu -- <명령>` | 작업자 여럿이 크롬(그림 뽑기)·일러 COM 을 한 번에 한 명만 쓰게 하는 `mkdir` 잠금. 30분 넘은 잠금은 죽은 걸로 본다 |
| `multitrace.py <x4.png> <out.svg> [--split-red] [--close N] [--rect-color cream\|none]` | 팔레트 색별 potrace(`ad.relogo._potrace_d`) → 단색 칠 SVG. 바탕 네모는 정확한 직사각형으로. 빨강은 `r−max(g,b)>60` 만(숨은 빨간 조각 방지). 먹 선은 가시를 깎고 가장 큰 덩이만. 팔레트·부위 규칙은 고객B 기준이라 **다른 건이면 복사해서 고쳐라** |
| `save_cs6.py <in.ai\|svg> <out.ai> [--cc]` | 일러로 열어 글자를 윤곽선으로 → CS6(ILLUSTRATOR16, 기본) 또는 CC(17) 저장. 내가 연 문서만 닫는다. 성공해도 `undefined` 를 찍는다 — 파일 머리 `Illustrator(R) 16.0` 으로 확인 |
| `예시_세로현판/` | 에이전트 A: 글꼴 비교(`fontcmp`) · 구역별 열기/닫기로 바늘 끝 고치기(`letters_fix`) · 끝 굵기 단면(`tips`) · 일러 점검(`inspect_ai`) · 지붕 따기·조립 |
| `예시_한지반전/` | 에이전트 B: 기하 재건축 한 방(`build` — 틀 다각형·기와 복제·대칭) · 마디 접선 꺾임(`joints`) · 끝 굵기/주 획 비(`tipcheck`) · 일러 점검·패스 이름 붙이기 |

⚠️ `예시_*` 는 **경로가 박혀 있다**(원안·작업 폴더). 복사해서 경로부터 고쳐 쓴다.
