# /design — 한 건을 처음부터 끝까지

> **뭐냐:** 이 하네스의 입구. 헌법 [`CLAUDE.md`](../../../CLAUDE.md) 의 «한 건의 순서»를 그대로 밟게 하는 체크리스트.
> **언제 읽나:** 디자인 일을 하나 받았을 때. 이어서 하는 건이면 `jobs/<건>/JOB.md` 부터.
> **안 담는 것:** 갈래별 세부 → `protocols/` · 질문 목록 → `INTAKE.md`.

```
/design <요청 한 줄>
예) /design 고객J 작업방에 새 ai 올라왔어, 두 면 시뮬하고 A4 로
```

## 밟는 순서

1. **기록장 열기** — 새 건이면 `_TEMPLATE/JOB.md` 를 `jobs/<YYYY-MM>_<상호>/JOB.md` 로 복사. 이어서면 그 JOB.md 를 끝까지 읽는다.
2. **받기** — 작업방 목록을 시각순으로 떠서 **가장 최신 파일까지** 받고 크기 대조(`TOOLS.md` «받기»). JOB.md «받은 것»에 한 줄씩.
3. **가르기** — `TYPES.md` 에서 갈래를 고르고 그 프로토콜을 **끝까지** 읽는다(잘리면 offset). `LESSONS.md` 에서 그 갈래 태그를 훑는다.
3-1. 🔴 **사용 선언** — 손대기 전에 첫 문장: «수산나 디자이너 CLAUDE.md 의 <갈래> 프로토콜(`protocols/<파일>.md`)을 사용하겠습니다. 함께 보는 것: INTAKE §… · guides/… · LESSONS [태그] · 새 시도: …». 갈래가 바뀌면 다시 말하고, 끝 보고 첫 줄에 «사용한 프로토콜·새 시도 결과».
4. 🔴 **묻기** — `INTAKE.md` 공통 + 갈래 질문을 받은 자료에서 먼저 찾고, 못 찾은 것만 한 번에 선택지로 묻는다. 답이 없으면 «추정 X 로 진행»을 JOB.md 와 결과물에 남긴다.
5. **만들기** — 프로토콜 단계마다 «통과»를 숫자로 확인. 사람이 정정하면 그 자리에서 고치고 LESSONS 에 바로 한 줄.
6. **새 시도** — `CHALLENGES.md` 대기열에서 이 갈래에 맞는 것 하나 이상을 기본 길과 나란히. 결과를 채점해 적는다.
7. **검수** — `COMMERCIAL.md` 체크리스트 전부 + 전체 화면과 4배 확대 둘 다 눈으로.
8. **넘기기** — 드라이브 복사, 보고는 공식 말투(위치·검수 결과·확인할 것). 넘기기 직전에 작업방을 한 번 더 본다.
9. **쌓기** — JOB.md «겪은 것» → `LESSONS.md` 에 항목 하나씩(날짜·갈래·단계·무엇·고친 것). 두 번 이상 나온 교훈은 프로토콜 단계 «해라»로 올리고 LESSONS 줄에 «승격» 표시. 새 시도 결과는 `CHALLENGES.md`.

## 하지 마라
- 손님 파일이 있는데 내 이전 판을 고쳐서 내기 · 한 번에 여러 개 바꾸기 · 모호한 말을 한쪽으로 찍기
- 기록 문서를 통째로 다시 쓰기(항목 하나씩만)
- 손님 연락처·실명을 `jobs/` 밖에 적기
